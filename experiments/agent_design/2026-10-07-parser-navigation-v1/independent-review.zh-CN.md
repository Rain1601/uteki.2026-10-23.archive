## Query 与 handoff

独立 Query 样例包含 5 块：正文、导航、导航、正文、末尾导航。每次读取 1 块，从第一导航开始：

| 版本 | 返回正文块序列 | 状态 | 末尾行为 |
|---|---|---|---|
| `.8` | b1、b2、b3、b4 | 全部 `read` | 保留旧消费行为 |
| `.9` / `.10` | 空、空、b3、空 | `layout_only`、`layout_only`、`read`、`layout_only` | 仅最后一页 `node_complete=true`，无下一游标；空页不是未披露 |

搜索同一导航短语时，旧版本有 3 条，新版本为 0 条，但均 `not_disclosed=false`。读块的省略 ID 全量返回；搜索预览才有 12 条省略 ID 上限及总数标志。

handoff 独立检查了真实 QueryDataPort 的“12 个正文块 + 尾导航页”。12 个正文全部进入审查输入，尾导航进入省略清单，coverage 明确排除了重复导航。其他检查验证了重复空页无进度、相同游标即使给出新省略 ID、没有正文，以及未确认的空省略均失败。源码中 `gaps` 与非支持状态继续抛错，未见这次改动吞掉错误或伪造正文进展。
