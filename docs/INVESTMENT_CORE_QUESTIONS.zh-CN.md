# Uteki 核心投资问题清单

日期：2026 年 10 月 6 日。撰写：Codex，供 Uteki 投资原则讨论使用。

本文整理买入、持有、加减仓、退出、现金和风险管理中的核心问题，帮助我们逐项形成明确的投资原则。我的建议是：以企业研究和估值决定投资吸引力，允许有依据的组合防御，同时把退出、重新入场和效果评价一起设计。

本文包含三种不同状态：**已确认原则**来自现有讨论及项目文档；**我的建议**是本次提出的判断；**待讨论问题**尚未形成具体政策。清单不是交易指令，也不意味着相关 Agent 或账户能力已经实现。

## 我的判断

### 允许主动防御并明确它的依据

我赞成保留主动减仓、甚至阶段性全现金的选择。公司没有经营恶化，并不意味着当前价格仍值得持有，或者当前组合仍适合承担原来的风险。严格要求等到企业出问题才卖，容易忽略估值过高、共同风险过大和资金承受能力的变化。

但我不建议把“市场涨了很多”“美联储加息”直接设为统一清仓条件。宏观变化应先落实到企业现金流、融资条件、估值假设和组合暴露。只有说清改变了什么，才能判断应该动哪一笔仓位、动多少，以及保留多少现金。

我建议先采用三层决策依据：

| 层次 | 我建议怎样处理 | 需要保留的依据 |
| --- | --- | --- |
| 企业与价值 | 根据投资判断、估值和替代机会决定持有吸引力 | 支持与反对证据、价值区间、当前价格隐含预期 |
| 组合承受能力 | 根据共同风险、集中度和流动性调整仓位 | 压力情景、损失来源、事前约定的限制 |
| 独立宏观择时 | 若企业判断、估值及组合约束都没有变化，仍因预期大盘下跌而减仓，单独记录和检验这项判断 | 当时可见的信息、预计传导、减仓范围、重新入场条件及对照结果 |

第三层并非禁止项，应在方法版本中明确是否包含独立宏观择时。既定方法内自主决策，实质扩展按方法升级规则处理，并对宏观择时单独评价。不能把每一次对市场的不安都解释成必须防御，也不能把“长期价值投资”当成不处理新风险的理由。

Howard Marks 在《Taking the Temperature》中讨论过极端市场环境下调整攻守程度，也强调这类判断不宜频繁。它提供的是一种投资者的思路，不能证明我们已经具备识别市场拐点的能力。[原文](https://www.oaktreecapital.com/insights/memo/taking-the-temperature)

### 退出和重新入场必须一起考虑

我认为一次防御决定至少应同时写清：为什么减仓、保留什么、等待什么、何时复查，以及什么条件下恢复投资。重新入场的依据应允许独立于原卖出价；若判断错误，不能仅因为价格更高就无限期等待。

卖出后，现金等待、踏空和重新入场都会影响最终结果。《Selling Out》同样强调，退出避险还包含判断下跌是否发生、何时买回以及如何使用卖出所得等问题。[原文](https://www.oaktreecapital.com/insights/memo/selling-out)

因此，我支持的目标是**在事前定义的风险约束内改善长期投资结果**。能否成功减少某一轮回撤，需要检验；不能承诺既避开下跌又完整参与所有上涨。

### 价格变化可以触发复核

我不建议当前为所有 Manager 设置同一个价格止损百分比。价格触发复核、价格触发必须减仓、投资判断失效后退出，是三类不同规则，应分别讨论。

价值投资也需要严格纪律：重要反证不能拖延，估值变化不能忽略，组合硬限制不能因“长期看好”而失效。这里的严格首先体现在证据、处置和责任上。任何回撤阈值都不应被描述成保证实际损失不超过该数值。

### 加息案例带来的启示

这一轮美联储首次加息发生在 2022 年 3 月 16 日；2023 年 7 月 26 日仍继续加息。与此同时，Nasdaq 100 在 2023 全年的价格回报为 53.8%。这些事实说明，加息与股票下跌并不存在一一对应的时间关系；它们本身不构成对任何退出策略的完整检验。[2022 年美联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20220316a.htm)、[2023 年美联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230726a.htm)、[Nasdaq 年度表现](https://www.nasdaq.com/articles/nasdaq-index-performance-december-2023)

对于“加息时希望退出”的想法，我建议把它转成可回答的问题：这次政策变化有多少尚未进入价格？它使哪家公司更不值得持有？如果价格先变得便宜而政策还没转向，我们是否愿意买回？

## 讨论的现有边界

下表依据当前项目文档核对。它描述已记录的产品和投资政策，不代表实际账户或执行能力已经验收。

| 事项 | 已记录的原则 | 本次还要明确的部分 |
| --- | --- | --- |
| 资产范围 | 公司个股和现金，只做多、无杠杆；ETF 用作对照 | 具体公司是否符合研究与买入条件 |
| 现金 | 允许部分或全部现金 | 什么条件下主动防御，什么条件下结束等待 |
| 集中持仓 | 允许有依据的集中持仓 | 单公司及共同风险的约束；三到五家公司是当前讨论规模，不代表必须买满 |
| 方法 | 长期价值和有基本面或事件依据的阶段性进攻分别定义 | 各自的买入、退出、期限和风险规则，不能混用一套阈值 |
| 账户 | 每位 Manager 独立、持续的模拟账户 | 后续机构或用户汇总资金时的分配与共同风险政策 |
| 对照 | SPY 为共同主 ETF 对照，QQQ 为补充；各账户匹配自身起点 | 如何评价防御、集中度及主动调仓的效果，不因跑输而事后换基准 |
| 实验口径 | 已登记模拟成本、现金参考计息及税前口径 | 按既定口径比较，不将实验假设说成真实券商收益或成交保障 |
| 方法变更 | 方法内自主决策；实质升级先形成新实验版本 | 什么变化构成风险政策或投资方法的实质升级 |

依据：[目标架构中的已确认要求](UTEKI_TARGET_ARCHITECTURE_2026-09-24.zh-CN.md)、[后续政策确认](UTEKI_ARCHITECTURE_PROPOSED_ANSWERS_2026-09-29.zh-CN.md)。早期[投资与评估章程](INVESTMENT_EVALUATION_CHARTER.zh-CN.md)中“偏向充分投资”和部分“待配置”表述已有后续细化；本文按较新的明确确认理解边界，不在本次改写历史文档。

## 如何使用这份清单

以下 60 个问题覆盖两类工作：账户或策略层面的原则，以及每次投资需要回答的具体问题。已有原则不需要反复重新批准；清单用于补齐适用条件，并检查实际决定是否符合原则。

每次讨论一问。答案至少写清**结论、依据、适用范围和重新审查条件**。缺少证据时记录“待验证”及如何验证；尚未作出政策取舍时记录“待决定”。不能把这两类空缺混成一个答案。

先写原则和失效条件，再根据明确情景讨论数值。本文不预设统一仓位、回撤或止损阈值。CFA Institute 对投资政策的说明也强调把目标、承受能力、期限、流动性和职责写清；本清单借鉴这些内容，不将某一套比例包装成通用标准。[CFA 投资政策说明](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-iii-c)

### 投资目标与可接受的代价

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q01 | 每位 Manager 希望在什么期限内实现什么投资结果？ | 声明收益与风险目标、观察期限及对照口径；沿用按风格评价原则，不只回答“跑赢市场” |
| Q02 | 为减少回撤，我们愿意接受哪些防御错误及多大的代价？ | 对提前卖出、错过上涨、频繁进出和较高价格买回分别表明容忍边界 |
| Q03 | 公司判断和估值仍有吸引力时，宏观判断能否独立降低股票总仓位？ | 允许、不允许或限定情形允许；明确适用条件、决策权限和证据要求 |
| Q04 | 哪些资金可以长期承担股票风险，哪些必须满足确定的流动性需要？ | 当前固定模拟账户沿用无追加或提取的约定；将来接入用户资金时另列期限和提款需求，不把两者混用 |
| Q05 | 各种投资方法允许等待经营判断兑现多长时间？ | 长期价值与阶段性机会分别列出判断期限、关键节点和超期处理原则 |
| Q06 | 除已经确认的共同约束外，哪些规则应由所有 Manager 共用，哪些可以按风格自行制定？ | 给出共同规则与风格规则的边界；不要临时将某一经理的偏好升级为全机构政策 |

### 公司理解与投资判断

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q07 | 这家公司如何把客户需求转化为股东可获得的现金？ | 客户与付费者、产品、利润、资本投入和现金回收的因果关系 |
| Q08 | 我们认为可持续的竞争优势，分别由哪些事实支持？ | 优势的具体机制、证据和削弱它的条件，不能只写“龙头”或“护城河” |
| Q09 | 公司新增投入能否产生足够的增量回报？ | 再投资、并购、回购、分红及融资的取舍，说明现金用途和回报的不确定性 |
| Q10 | 买入所依赖的核心判断中，哪些已经发生，哪些仍是预测？ | 每条关键假设的事实基础、预计兑现时间和验证方式 |
| Q11 | 目前最有力的反对证据是什么，它是否改变我们的判断？ | 保留最强反方论点，给出接受、部分接受或不接受的理由 |
| Q12 | 哪些尚未弄清的问题足以阻止买入？ | 区分必须补齐的关键缺口与可以在有限仓位下承担的不确定性，列出证据来源要求 |

### 估值与预期回报

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q13 | 企业经营最终能转化为多少每股股东收益？ | 收入、利润、资本开支、营运资金、债务及股数变化的口径，避免把利润直接当作可分配现金 |
| Q14 | 当前价格要求公司未来做到什么，我们为何认为市场预期有偏差？ | 价格隐含的增长、利润或资本回报，与自己的假设逐项比较 |
| Q15 | 在不利、基准和有利情景下，从当前价格出发的回报分别如何？ | 统一期限、现金分配和终值假设；区分计算结果与估计，不强行为未知情景编造概率 |
| Q16 | 考虑估值误差后，什么价格范围才足以支持买入或继续持有？ | 合理价值区间、要求的安全余地及依据，不用一个精确目标价掩盖模型不确定性 |
| Q17 | 哪些变量最容易改变估值结论？ | 利率、增长、利润、资本投入等敏感项，并检查同一风险是否被无说明地重复计入 |
| Q18 | 与其他已研究公司或现金相比，这笔投资的优势是什么？ | 比较预期回报、风险、研究把握和转换成本；ETF 继续作机会成本对照，不因此进入可投资范围 |

### 买入与建立仓位

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q19 | 一家公司从“值得研究”进入“可以买入”，必须满足哪些条件？ | 对研究充分性、估值、证据、资金和风险给出最低要求；不要求凑满持仓数量 |
| Q20 | 为什么现在买比继续等待更合适？ | 当前价格和证据带来的机会、等待的好处与代价；催化剂可有可无，但必须说明选择依据 |
| Q21 | 哪种失败情景决定这笔投资的初始仓位？ | 同时考虑损失幅度、判断不确定性、共同风险和可退出性，给出目标比例的理由 |
| Q22 | 分批建仓时，下一笔买入由什么条件触发？ | 区分价格改善、证据增强和计划执行；不能仅因上一笔亏损就自动加仓 |
| Q23 | 买入前出现矛盾或迟到信息时，什么情况下暂停原决定？ | 明确使原判断需要复核的变化，以及继续、缩小或取消方案的依据 |
| Q24 | 当前价格、流动性和交易摩擦是否使买入仍值得执行？ | 可接受价格范围、有效期、资金与成本；按既定模拟时点处理，不补造错过的成交 |

### 持有与加减仓

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q25 | 从今天的价格和信息出发，继续持有的理由是什么？ | 更新未来回报与替代机会；买入成本不单独决定持有，转换成本仍需考虑 |
| Q26 | 哪些新证据会改变当前持有判断？ | 为核心假设指定可观察指标、来源和支持或反驳方向；没有新材料不等于判断被验证 |
| Q27 | 股价下跌后，什么条件支持加仓而非维持或减仓？ | 解释价格更便宜与价值下降的区别，并重新检查组合暴露及承受能力 |
| Q28 | 股价上涨使仓位变大时，什么条件支持继续持有而非减仓？ | 同时检查价值增长、估值变化和集中风险，不只根据浮盈决定 |
| Q29 | 预期中的改善迟迟未兑现时，什么时候停止延长等待？ | 原验证窗口、合理延期证据、等待成本及必须重新决策的节点 |
| Q30 | 哪些事项必须立即复核，哪些可以等到例行复盘？ | 重大反证、来源更正和风险异常的处理时限与责任人；频繁检查不等于频繁交易 |

### 卖出与重新入场

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q31 | 哪些事实足以判定原投资逻辑失效并要求退出审查？ | 可证伪条件及证据标准，例如核心竞争力、治理或现金创造机制受损；区分疑点与已证实变化 |
| Q32 | 公司仍然优秀时，价格高到什么程度会使持有不再合理？ | 从当前价格计算的未来回报、误差余地和替代机会，而非“已经涨了很多” |
| Q33 | 卖出理由互相冲突时，按什么顺序处理？ | 明确硬约束、投资判断失效、估值、替代机会与宏观担忧的优先级 |
| Q34 | 什么情况下只减仓，什么情况下完全退出？ | 说明问题是仓位过大、部分假设变弱还是整个投资依据失效，并给出剩余仓位的理由 |
| Q35 | 因不同原因卖出的公司，各自在什么条件下可以重新买入？ | 区分估值回落、风险缓解和经营修复；投资逻辑失效不能只靠价格更低就恢复 |
| Q36 | 卖出后判断被证明过于悲观，是否允许以更高价格买回？ | 按当时价值和机会重新评估，明确由谁复查及何时行动，不以原卖出价作为必须满足的条件 |

### 宏观防御与现金

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q37 | 什么可观察证据使我们认定市场或某个行业过热？ | 列出估值、融资、盈利预期或投资行为的具体异常，不能用上涨本身循环证明过热 |
| Q38 | 当前宏观变化会如何影响所持公司的价值，哪些影响已经反映在价格里？ | 写出变量到现金流、融资或估值的传导链，并列出不受影响或可能受益的情形 |
| Q39 | 什么证据组合足以使宏观担忧升级为减仓决定？ | 给出从关注到行动的条件、相反证据和判断失效条件；政策新闻不能自动替代这一判断 |
| Q40 | 决定防御时，具体先减哪些资产、保留哪些资产？ | 按共同暴露、估值和损失情景解释目标比例；不要机械地让所有公司同比例减仓 |
| Q41 | 当前持有的现金分别是在满足什么需要？ | 区分等待合格机会、主动防御和资金缓冲，记录参考收益及机会成本；模拟计息沿用已有约定 |
| Q42 | 什么条件意味着应该结束防御、恢复股票仓位？ | 给出复查频率、价值与风险条件、恢复方式；不得无限期等待“所有风险消失”或只等政策转向 |

### 组合风险与压力情景

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q43 | 我们最需要控制的损失是什么？ | 分别说明永久性资本损失、阶段性净值回撤、流动性不足及机会成本的重要性，避免混为一个风险分数 |
| Q44 | 表面上不同的持仓，可能因什么共同原因同时受损？ | 列出共同客户、行业投入、融资环境、地区或增长假设；公司数量不能代替这项分析 |
| Q45 | 单家公司和组合整体的风险边界应如何设定？ | 结合压力损失、流动性与已承诺资金说明约束及理由；集中持仓不自动等于违规 |
| Q46 | 价格下跌或组合回撤达到什么条件时，分别触发提醒、复核或必须行动？ | 三种处置分别定义口径、窗口、权限和例外；跳空、停牌或流动性不足导致无法按预期退出时，明确剩余风险的处置与复查责任。沿用每日检查、不承诺盘中止损的边界，阈值不是损失保障 |
| Q47 | 关键数据缺失、过时或不可信时，还允许采取哪些投资动作？ | 区分已有持仓与新增风险，明确可继续、须暂停或须限制的范围及补证期限 |
| Q48 | 哪些不利情景可能同时击穿研究判断和组合承受能力？ | 检查增长落空、估值收缩、融资或流动性恶化及其组合；区分假设压力损失与实际发生损失 |

### 团队职责与决定权限

| 编号 | 明确问题 | 答案需要落到什么 |
| --- | --- | --- |
| Q49 | 哪些决定属于既定方法内的自主判断，哪些属于必须另行确认的方法变更？ | 沿用方法内自主模拟的约定，明确新增宏观择时、放宽风险限制等变化是否越过原授权范围 |
| Q50 | Research、Portfolio 和 Risk 对同一投资存在分歧时，谁作最终决定？ | 区分研究结论、配置决定和约束处置，保留异议及接受或不接受的理由 |
| Q51 | Risk Manager 在哪些明确情形下可以阻止新增风险或要求降低风险？ | 分别约定提醒、复核、暂停和强制处置的权限；不能默认所有风险意见都有否决权 |
| Q52 | 多个 Manager 同时暴露于相同风险时，在哪一层作约束和资金决定？ | 保留当前独立模拟账户；后续机构或用户分配层明确资金权属与限制，不能直接相加仓位或平均收益 |

| Q54 | 人工修改或推翻系统决定后，如何保留原判断并评价结果？ | 记录修改内容、责任、时间和理由，分别比较原方案与实际处理，不回写历史美化成绩 |

### 复盘与策略有效性

| 编号 | 明确问题 | 答案需要落到什么 |

| Q55 | 收益究竟来自公司选择、市场上涨、集中暴露、仓位调整还是现金选择？ | 在统一时点与口径下分别说明贡献和无法识别的部分，不把所有盈利都归因于研究能力 |
| Q56 | 当投资判断与股价表现相反时，分别如何评价研究和决策？ | 用事前预测与实际经营核查研究，用当时可见信息核查决定，再独立记录投资结果 |

| Q60 | 规则修改后，如何检验改进且保留原方法的真实记录？ | 明确新版本、变更理由、前瞻生效时间和比较窗口；不以修改后的规则重写原先决定 |

## 建议优先讨论的六个问题

不需要一次回答全部问题。建议先完成下面六项，再围绕一家明确选定的公司检验原则是否能形成实际决定。

1. **Q02 防御的代价**：我们愿意承担哪一种错误，以及什么程度的代价。
2. **Q03 宏观判断的权限**：企业判断未变时，是否可以独立减仓。
3. **Q31 投资判断失效**：哪些证据要求我们承认原判断有问题。
4. **Q21 初始仓位**：什么失败情景决定一家公司能买多少。
5. **Q35 重新入场**：每类退出之后，凭什么恢复投资。
6. **Q51 Risk 的权限**：哪些意见是建议，哪些属于必须执行的既定约束。

其中 Q02 与 Q03 应先于具体宏观信号和止损比例。否则，很容易先设计出一套规则，随后才发现它要求我们承担并不愿意接受的代价。
