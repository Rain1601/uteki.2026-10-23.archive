用户已认可丝绸蓝侧栏 Logo，本轮只精简机构首页的重复标题与顶部空间。输入仍为已选机构、Agent、收益区间及模拟快照；输出是同一首页的一次排版迭代。

- 原工具栏和机构大标题合并为一个至少 56px 的页首；窄宽度允许自然换行。只保留一个投资总览标题，旧版对照入口放到设计说明中。

复核：通过减少重复信息和空白将视线引向表现与持仓，不更换配色或缩小数据来制造紧凑感。验收示例为打开首页看到单一标题与完整模拟身份，点 Field 后曲线、配置、事件同步；字体、语言、主题、上下文和报告往返保持有效。较窄窗口依靠换行和原生阅读滚动，不强制一屏裁切。程序检查不等同于页面视觉验收。

## 视觉参数

- 主体按约 8∶4 非对称列组织，列间 32px。顶部比较卡跨两列，机构标题、比较带、曲线共用外边线；右侧组合有独立浅色表面。内容不足 1000px 时上下阅读，不让图形挤成窄条。
- 色彩：白纸 `#ffffff`、次表面 `#f2f5f8`、主文字 `#15212e`、次文字 `#607080`、线 `#d8e0e7`、交互蓝 `#215bd1`。暗色独立使用石墨表面。分类色仍采用明快色卡，公司原 icon 与透明雨滴保留原样。
- 字体：本地 Helvetica Neue / Helvetica / Arial 与中文系统字体。机构标题 30px；比较收益 30px；组合名称 23px；区块标题 18px；列表正文 13–14px；元信息 12px。所有数值采用等宽数字，字号差异表达主次。
- 曲线 viewBox 与交易标记几何共同调整到更高的比例，由渲染器负责；CSS 不单独拉伸 SVG。图中保留买卖，报告事件在下方，过滤控件靠近事件轨道。
- 顶部只保留一组 Agent 卡，包含名称、区间收益与短曲线；有明确前后按钮。右侧删除重复收益，将 Agent 身份、准确快照日期和市值放在约 136px 环图旁，再呈现公司占比列表。减少独占一行的元信息，持仓行约 38px。
- 公司和 Manager 保留原三层外框，并共享新的标题、列表与连续阅读基线。长文保持 17px / 1.85，不将正文压成小字。

## 对投研工作流的复核

主要变化是视觉重心与空间分配，而非换字体和缩间距。用户同时看见相同区间的多 Agent 比较和当前选中组合，符合“表现如何、持有什么、由谁研究”的查看顺序。显著颜色优先服务分类与选中状态；边界保留适度圆角，不将瑞士设计简化为黑白直角。

保留模拟标签、日期、币种、报告作者及版本。点击公司直达选中 Agent 的报告；事件浮层、报告返回、双击查看历史与键盘操作继续有效。没有自动轮播、滚轮切对象、新交易或模型调用。自然阅读滚动是较小窗口的兜底。

## 验收例子与边界

1. 进入机构页，在同一主体横向看见大曲线与选中 Agent 的环图、公司占比。
2. 顶部点 Field，当前组合同步切到 Field，曲线与事件作用域一致；双击仍展开持仓历史。
3. 点曲线上买卖或下方报告，原浮层呈现准确日期与归属；关闭不丢阅读位置。
4. 从持仓进入报告再返回，保持当前 Agent 和选中配置。
5. 明暗主题和中英界面仍可用；小容器正常上下阅读，不强迫图表压缩或隐藏信息。

本目录现为持续迭代入口，历史 v2、A、B 保留。主任务完成的自动检查和几何核验见 README；此前未运行自动浏览器或截图，本次用户视觉认可不扩展该工程验证范围。后续公司、Manager 与报告细节按具体改动继续评审。
