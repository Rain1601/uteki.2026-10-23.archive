## 本轮要验证的行为

选择 Data 或 Analysis 工作区，再选择一项任务，能在同一窗口明确回答：任务要求什么、哪次运行、执行了哪些步骤、交付什么、证据在哪里、还有什么问题。打开产物后保留任务阅读位置；评审和追加要求分别记录。

| 区域 | 可操作内容 |
| --- | --- |
| 左栏 | Data / Analysis 切换；公司或任务搜索；状态筛选；任务选择 |
| 任务工作区 | 结果、过程、评审；历史运行选择；模型与配置版本标识 |
| 右侧检查面板 | 原文片段、表格、报告、结构化记录；返回所属任务及运行过程 |
| 人工评审 | 按任务、运行、标准保存判定和依据；草稿在切换产物、语言和任务后保留 |
| 追加要求 | 创建新的待执行演示尝试；历史输出保留，新尝试没有步骤或产物 |
| 评测与实验 | 固定同题、配置 A/B、逐条输出及判定；查看对应产物并定位运行 |

验收例子：Data → GOOGL 现金流任务 → 评审 → 填写未保存意见 → 打开表格与原文 → 返回，草稿仍在；再选择较早运行，查看缺少单位的示例 → 追加要求 → 新尝试明确为未执行。切换 Analysis 可查看研究任务关联的数据补充请求。

具名数据集包含 GOOGL / MSFT 两家公司、5 个任务、9 个产物、2 道实验样本。示例范围按任务和运行绑定；缺失/错误 ID、跨公司或跨运行产物引用报错，不自动替换。

## 边界

- 中英界面均可切换；采用原生滚动，键盘方向键仅在任务页签内切换页签。
- 评审、草稿与追加请求仅在当前页面内存保留，刷新清空。没有后端写入或真实任务执行。
- 过程是示例执行记录，不是隐式推理记录；实验输出和判定同样是虚构样例。
- 不调用模型，不运行采集，不改历史快照或共享采纳状态；未接入权限、持久化评审、调度、取消和恢复。
- 此页独立于旧 `/evaluation` 与前台公司报告原型；未删除或替换它们。
