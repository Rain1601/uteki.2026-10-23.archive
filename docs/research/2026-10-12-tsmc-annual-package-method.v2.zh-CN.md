# DS-03-T01 · 年度财务材料获取方法 v2

2026-10-12。用户选择台积电 FY2025，并要求由公司可变的方法获取，而非 Codex 手工准备材料。当前只实现、运行原件获取及重复校验；不启动模型提取或扩展 PPT/OCR。

## 输入、边界与停止点

显式输入：公司、财年、报告期末、数据截止日、版本化官方来源配置及输出目录。方法核对公司与配置，不以默认公司、最新报告或另一公司的材料补缺。首个配置是 TSM／CIK 0001046179，FY2025／2025-12-31，截至 2026-10-12。台积电使用 20-F；原 US GAAP／10-K 的 DS-02 契约不改。

年度合并财务包覆盖：SEC 年度原报及同期间修订、申报目录中的附件与 XBRL 文件；官方年度报告网页／完整原件；官方年度合并财务报告；官方 20-F 镜像。主表、全部附注及相关年度财务披露是后续内容核验的分母，不用获取到的文件数证明财务事实完整。母公司单体报表、季度／月营收、演示与音频不纳入本批次。

## v2 修订依据

v1 将 78 个请求平均划分为三轮，每轮 26 个。实际 SEC 原报／索引／附件／XBRL 共 27 件，另有官网目录和年度原件，额度先被 SEC 附件用完，遗漏了 2 件 XBRL 与全部 IR 材料。保留 v1 运行：25 件三次真实 HTTP 200、字节稳定，27 件已发现，官网尚未发现；未称完整通过。

v2 加入有证据的续取：显式指定上一验证文件与 SHA-256，核验公司、期间、截止日、存储、逐轮文件封存与原件 hash。仅复用已经三次真实取得且字节一致的材料；旧请求时间／URL／响应保留，本地再核验不能算新的远程取得。当前目录仍重新发现，新增、变化、缺件及未验证材料继续执行三次获取。分母保留，不重下无变化的 25 件。

本次续取仍最多 78 个新 HTTP 请求、240 MiB 响应，沿用首轮失败和 80 次实际尝试记录；这是有明确缺件的新增有界批次，不重置历史记录，也不自动提高模型／采购额度。请求护栏耗尽时当轮保存后停止，不再无变化重复耗尽后续轮次。

## 方法

公司参数 → 核验发行人 → 按报告期间／截止日发现 SEC 原报 → 解析版本化官方目录规则 → 保存应取清单 → 获取原件 → 重复校验 → 输出已取、失败、变化和缺件。

- 复用现有 SEC 发行人／报告身份核验。公司官网路径、目录标题及链接选择规则只在显式配置中；不在执行代码中写台积电答案或文件 URL。
- 每件材料需三次真实非条件远程取得；可继承经 hash 绑定的既有三次记录。记录请求时间、URL／最终 URL、HTTP 状态、类型、字节数及 SHA-256；本地复用或 304 不算重复取得。失败保留，不做第四次无变化重跑。
- 同 URL 不同 hash 标为内容变化，保留各版；不同 URL 同 hash 标为字节相同副本，保留来源关系。HTML 与 PDF、年报与 20-F 内容相似不自动合并，不把重复披露相加。
- 目录发现有缺口时清单标为不完整；未找到修订不等于已验证没有修订。修订、缺件和失败不移出分母。
- 原始 PDF 可作为原件存档，但本轮不实现 PDF 解析。HTML／XBRL 留给下一步文本解析；PDF 独有披露作为格式缺口，不能称全文已解析。

首轮 v1 护栏：最多 80 次 HTTP 请求（重定向、失败均计入）、40 件材料、单响应 32 MiB、总响应 256 MiB；请求间隔至少 0.5 秒，单次超时 40 秒，最多一次临时网络重试。403／身份／格式错误不重试；429 按 Retry-After 延后。只用免费官方源，零模型调用。护栏触发保存未完成清单并停止。

## 验收

获取：应取目录独立保留；必需材料角色齐全，SEC 公司／form／期末验证通过，原件类型合法，原件与 hash 一致。目录或身份未知保留缺口，不能标完整。

重复：每件三次远程记录齐全、hash 相同才记字节稳定；内容变化／失败分别报告。跨 URL 的字节重复保留出处，禁止跨公司或跨期间复用。三次请求不证明长期稳定性。

解析（下一任务）：主表／附注逐项对账；原值、币种／倍率、符号、时点／期间、合并范围、维度、版本和精确出处正确；不得只验几项摘要。获取通过不等于解析通过。

迁移：使用独立合成发行人验证参数生效、错公司／错期间／缺原报／修订／重复／变化／失败边界。配置适配不等于已经支持所有公司。

官方入口：[年度报告](https://investor.tsmc.com/english/annual-reports)、[完整财报目录](https://investor.tsmc.com/english/financial-reports)、[SEC 申报目录](https://investor.tsmc.com/english/sec-filings)。目录观察完成，原件须由方法实际运行取得。
