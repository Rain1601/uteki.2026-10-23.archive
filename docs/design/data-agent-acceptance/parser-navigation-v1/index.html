如何验收 Acceptance

  1. 独立核对原件先从原 DOM 和目录链接固定期望值，不把解析器自己的输出当答案。
  2. 比较实际产物导航仅增加标记；标题仅增加目录识别。两阶段的原文字段、块 ID 和表格内容均保持。
  3. 验证消费边界和版本检查默认 search/read、空返回和续读边界。旧包保留；新版在同环境重建并比较文件。

独立基准的 16 个原始用例已全部执行：10 个满足原预期，6 个保守拒识或诊断粒度不足。包括单项目录、缺 Part 或唯一目录锚点等情况；原文保留，但尚未产生预期导航/章节。本轮不把这些限制计作通过，也不据此宣称通用解析已完成。

原件核对与边界 / Independent review阶段汇总 / Stage checks独立复查 / Review下游完整阅读检查 / Consumer check支持范围补件 / Limits

这些是离线程序与原件结构检查。全文语义、所有图片/脚注、模型质量、实际 token 节省和通用多格式支持仍未完成。页面的文件与定位链接由程序核对，浏览器视觉审核未执行。
