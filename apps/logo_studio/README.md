## 颜色流动

`color-flow-renderer.js` 把原 JPEG 裁切区域作为纹理，用固定的采样坐标生成透明颜色叠层。底层原图一直显示；不存在 UV 位移、变形、几何重建、替代材质、粒子或新增高光条纹。字标仍直接使用原图裁切，不经过渲染器。

冰蓝色带从尖端向底部传播，后方跟随深蓝尾部；两侧沿弯曲路径存在相位差，6 秒循环。原图颜色经过 screen / multiply 混合，形成可追踪的色度与明暗变化，同时保留原图局部纹理。白底、S 形白色留白及近白高光不参与变化；高光边缘的变化平滑减弱。默认幅度 80%，叠层 alpha 最大为 `0.85 × 幅度 × 蓝色掩膜`。幅度可以降到 0 或切回原图。它是颜色流动，不是液体形变或物理玻璃模拟。

上一版 9 秒循环只做微弱曝光变化，默认最终变化上限约 ±6.6%，用户反馈无法辨认流动。本次调整了色彩路径、色差和周期；控制器只累计播放时间，循环周期统一由 renderer 管理。脚本 URL 添加版本号，避免浏览器继续使用旧效果。

「原图」立即隐藏叠层、停止动画帧并保留原图像素；幅度为 0 时输出完全透明、停止调度。暂停固定在当前颜色帧，后台标签页暂停且不补算隐藏时间。遵循减少动态偏好：切换到颜色流动时仍暂停，显式点击播放才运行。

同页保留琉璃蓝/丝绸蓝两套原图、语言和纯净欣赏。新素材加载失败保留上一张图，渲染器初始化、纹理上传或绘制失败会退回原图并给出说明。页面通过本地 HTTP 浏览；部分浏览器限制 file:// 图片作为 GPU 纹理，遇到限制仍保留原图。
