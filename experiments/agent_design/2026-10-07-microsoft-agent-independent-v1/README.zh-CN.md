## 独立性的边界

输入材料由之前的工程准备冻结；本轮验证加工阶段的独立性，不声称 Agent 自动发现并获取了报告。规则来自同一材料上的方法迭代，因此属于同材料复跑，不是未知公司盲测。Codex 负责开发和事后评审，运行中不手工改事实、不传参照答案。

`input-isolation-audit.json` 核查实际请求，确认与参考使用完全相同的源文包、初次用户输入仅为原文、系统提示没有旧候选或公司专属节点反馈。比较页及事后评价允许读取参考；它们不参与生成。

## 验收

1. 独立性：初次仅原文与规则；修订仅本次自己的响应及程序错误。保留每次真实请求和响应。
2. 交付：系统自动输出新候选、Trace、配置、出处与费用；失败如实展示。不能用参考图填补失败版。
3. 质量：封存后按原文检查重要业务覆盖、对象身份、整体/子集关系和引用支持；不以节点数量相同或JSON合法代替质量。Codex 事后指出的缺口不会回填本次运行。
4. 展示：左右两版沿用相同 Mermaid 基线；原文、固定索引和各自过程可打开。
