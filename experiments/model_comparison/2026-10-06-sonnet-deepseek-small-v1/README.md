# Sonnet 5.5 与 DeepSeek Pro：小材料提取及短分析

日期：2026-10-06。状态：已发起两次真实请求。Sonnet 返回完整结果，DeepSeek high 推理在输出上限内未完成。实际结果与用户随后提出的分层流程见 [RESULTS.zh-CN.md](RESULTS.zh-CN.md)，不形成模型通用排名。

用户希望比较模型，同时避免把整份财报反复输入。第一轮使用 AMD FY2023 的一张完整现金流表与两段管理层说明；同一输入交给 AiHubMix `claude-sonnet-5-5` 和官方 `deepseek-v4-pro`。这是一项具名、小范围实验，不是应用的默认公司、期间或模型配置。

## 本轮问题与边界

- 从原文提取 2023、2022 的经营、投资、融资现金流，共 6 条事实。保留数值正负、期间、单位及原文出处。
- 用短分析解释资料中所述的 2023 年经营现金流变化，区分管理层解释与模型推断，并列出节选不足以回答的问题。
- 提取准确性与解释质量分开评价；分析使用本次模型读到的材料，不能代表“给定相同正确事实后的纯分析能力”。后者需要第二项独立实验。
- 每个模型只做一次独立请求，无工具、搜索、自动重试或输出修复。输出各限 4,000 Token。本地估算预算为 0.20 USD，不是服务商强制扣费上限；未知费用会阻止后续请求。
- Sonnet 使用该接口默认推理行为；DeepSeek 显式启用 high 思考。它们不是相同计算量，结果只比较这两套明确配置，不归因于模型品牌本身。
- 单个小节、每模型一次只能作为试跑。不能据此宣布通用胜率、全年报覆盖率或完整报告质量。

## 证据与评审

`prepared/packet.json` 保存任务、范围、原文块及表格的机械投影。省略空单元格，但保留完整非空数据、原行列及跨格信息；不把历史提取候选当输入。`prepared/manifest.json` 绑定来源与文件哈希。

`prepared/reference-review.json` 单独记录从原始资料复核的参考项，不进入模型请求。它是代理的来源核验，不是独立人工 Gold，也不会改变数据工作台的采纳状态。

| 维度 | 检查方式 |
| --- | --- |
| 数字 | 逐条核对公司、指标、财年、单位、正负与金额；分别报告正确、错误、缺失和额外记录 |
| 证据 | 核对引用块身份和逐字引文，再核对引用是否真的支持该指标与结论 |
| 分析 | 是否回答变化问题、是否保留管理层归因、是否混淆事实与推断、是否指出关键限制 |
| 工程 | JSON 可解析、完整结束、输出契约与来源范围有效；格式通过不等于语义通过 |
| 消耗 | 请求数、供应商返回用量、耗时与公开价格估算；推理 Token 不重复加到输出费用 |

比较完整保留两边结果和失败，不挑选最佳答案。没有返回可用结果时，仅报告连接或接口状态，不形成模型质量排名。

## 运行方式

从仓库根目录执行本目录 `run_comparison.py`，指定新的 `--output` 目录。脚本会校验准备材料、使用现有本机凭据加载器，并把公开请求内容与受限字段投影后的响应记录到新目录。凭据和原始错误内容不写入实验文件。

价格参考：[Sonnet 5.5](https://aihubmix.com/model/claude-sonnet-5-5)、[DeepSeek 官方](https://api-docs.deepseek.com/quick_start/pricing/)。调用记录保存本次实际使用的价格快照；估算不计缓存、闲时或账户折扣。
