# A / B 阶段验收边界补件

本补件追加说明，不改写任何阶段包或既有回执。独立评审将原始 16 个 oracle 样例全部执行：10 个符合原预期；6 个因当前资格限制保守拒识或诊断较粗。不能表述为“16 个样例全部满足原预期”。详细样例与实际回执以独立评审记录为准。

- **A 的目录门槛：** 必须先检测到含至少 2 个 Item 行及内部链接的目录。单 Item 目录中的重复回链本轮不支持，保留原文。导航块还需完整短 `Table of Contents` 文字、唯一可见目录目标，以及同目标、标签和版式的至少 2 次重复。字号和行高不参与重复分组；不做 CSS 单位换算。带页码或混合文字的回链本轮保守保留。
- **真正目录标题：** 即使它含自链接，也根据目标自身及包含关系予以保留。script/style/noscript 及其后代不可作为可见目录目标。
- **B 的资格门槛：** 单行两列表格标题还需可验证的 Part、目录 Item 身份、标题及准确锚点。目录缺 Part、缺目录、无锚点、嵌套或不支持的表格/文字形式可能不发布节点；某些原因只报告 `missing_unique_toc_identity` 或 `item_unresolved`。本轮不扩充这些支持范围。
- **短引用与标题：** 非表格 Item 文字在新版本中须精确对应目录标题，或具备明确标题版式。普通短句、长句及带句点的叙事引用不会仅因开头含 Item 就成为章节。旧版本行为保留。
- **导航范围：** 节点表示源文件连续区间，只允许移除尾部布局块作为结束边界；不判断每段内容的语义归属。尤其不能将 TSMC Item 19 后的签名、财务索引及 F 页自动理解为 Exhibits。
- **下游使用：** 默认 search/read 及 Query 的对应入口实际过滤重复导航；仅导航页明确返回 `layout_only`，不算已读正文。原始 HTML、解析 document.html、blocks 和显式选块的提取入口仍保留原文。没有执行模型、计量实际模型输入节省，或完成整文金融语义验收。

本次交付以最终阶段包、阶段回执、独立复核和本补件一起构成验收依据。两个 `pre-publication-attempt-*` 目录只保存未发布构建过程，不属于正式验收产物。
