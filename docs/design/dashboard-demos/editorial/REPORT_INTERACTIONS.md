# ES08.1 · 研究报告阅读交互调研

2026-10-10。目标：让研究人员与决策者快速了解结论、定位章节、核对证据、读懂图表。输入为公开报告与现有编辑风格组件；本轮交付调研与组件候选，未新增报告运行页或真实研究结果。

## 结论

推荐“摘要 → 正文 → 就地核对”的阅读结构。首屏用明确标题、日期/范围和三条结论建立方向；正文保持连续阅读，目录常驻但紧凑；脚注、口径、图表细节按需打开。编辑设计感来自文字层级、版心、图注与留白，操作只出现在读者需要的位置。

## 组件候选与采用顺序（设计建议，未实现）

| ID | 读者动作 | 候选组件 | 简洁规则 | 可判定验收 |
|---|---|---|---|---|
| RR01 | 先理解报告说什么 | ReportBrief：标题、范围、三条结论 | 常显短摘要；事实/判断/待确认用文字区分，避免装饰性评分 | 每条结论能定位支撑章节；缺口与判断不呈现为已核实事实 |
| RR02 | 去某一节，再继续读 | ReportOutline：桌面窄目录/紧凑章节选择 | 只展开当前章的二级标题；视觉与键盘焦点可辨 | 点击/键盘均能定位，不被顶栏遮挡；当前章与URL一致；浏览器返回可回退 |
| RR03 | 核对一句话或术语 | InlineNote + 既有Citation/SourcePanel | 短解释浮层，长证据面板；一个时刻只开一个辅助阅读层 | 查看引用→准确摘录→返回原滚动/焦点；触屏不依赖hover |
| RR04 | 看趋势，再核对数字 | ReportFigure：图表/数据/口径 | 默认图表；图下常显编号、单位、期间、来源，详细规则展开 | 两视图共享显式数据范围/选择；切换不变高度；缺失值不补0；离开后可恢复 |
| RR05 | 理解假设如何影响结论 | ScenarioFigure：少量参数与基准对照 | 只在内容需要时出现；明确示例/预测标签与重置入口 | 改一个参数只变相关图文；单位/假设清楚；可恢复基准；减少动态效果时仍可读 |

RR01/02为这次调研衍生的产品建议；RR03/04有上表操作依据；RR05是后续候选，本轮没有实测合适的报告参数交互，不计为已调研完成。

报告对比留作后续：先明确要比较公司、期间还是版本，再决定对齐结构，不能把任意两份PDF并排称为有效对比。章节/摘要、图表数据与来源之间应传显式报告ID、章节ID、图ID和来源ID；缺失映射显示缺口，不以第一项替代。

## 与既有组件衔接

来源摘录与集中面板已交付，可复用精确来源定位、关闭返回；图表联动/图片局部放大已有原型。新的报告壳优先补摘要、章节导航和图表/数据切换，避免再复制一套引用和媒体实现。字体沿用已认可的阅读/操作角色：中文正文使用可靠中文字体，英文展示可用衬线；表格数字无衬线与等宽数字；主题使用现有语义变量。

建议版心：正文约680–760px，图表可横向扩展；正文17–18px、行高1.75–1.85（中文需实际内容验收）；章间56–72px，图注13–14px。这些是待验证设计参数，不是测得的Anthropic品牌规范。动效建议150–220ms只用于打开/关闭与状态过渡；尊重prefers-reduced-motion，不自动播放阅读素材。
