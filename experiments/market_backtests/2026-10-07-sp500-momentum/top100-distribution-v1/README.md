# BT-08 前100名行业散点分布

按 2025 全年复权收益，在原年末固定500只可排名证券中选择前100；对应11个大行业。每行业一张图，同批证券2025/2026各一个点（共200点）。默认纵轴为减去行业均值后的收益差，单位百分点，横线0位于中心。可切换实际收益、各行业局部刻度、前100子组均值。横向避让无统计含义。

平均：默认全行业可比证券的初始等权买入持有收益，含自身，明确不同于上一版剔除自身的逐股同行比较。子组均值只包含前100中该行业证券。两年可比集合固定排除缺全年权益的SNDK、Q、PSKY。年份区间不同、未年化，2026截至10月6日。这里展示股票收益，非公司营收增长。行业字段沿用原名单，未新增分类或因果假设。

input_results.json保留本次冻结输入，data.json有输入SHA256与计算配置；top100.csv为全部明细。build.py只在不存在快照时首次复制上游，随后稳定复用。运行 python3 build.py 生成 report.html。

验证：独立核对100个唯一排名和所有行业两种均值；实际页面脚本在模拟DOM中检查11图、200点、8种控制组合、260px图宽的有效数值；子组偏离之和为零、偏离刻度关于0对称。未进行浏览器视觉验收，未声称因果解释或新策略收益。
