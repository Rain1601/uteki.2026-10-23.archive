## 核查方法与实际证据

程序从原始 HTML 的每个正文文本节点和尾随文本出发，不以已有 blocks 清单作为覆盖全集。每个非空片段均记录原文、DOM 路径、节区间、所属块及处置原因。隐藏内容/脚本按现有内联可见性规则排除，并同样留账；没有把所有不可见内容直接丢掉不记录。另逐块比较原 DOM 的规范化文本与已存正文，并检查块的 DOM 顺序。

三个完整处置账以 `*-text-ledger.jsonl.gz` 保存，解压可检查每一个片段；对应 SHA-256 保留在 `*-coverage.json`。原件、source、manifest、index 和 blocks 的输入哈希保留在记录中。所有原件及历史底稿检查前后哈希一致。

Part 开头和每个 Item 都形成独立、不重叠的导航区间，前置封面单列。导航区间不表示里面每块都具有相同业务主题。已有目录诊断完整保留，不隐去导航误差警告。
