## 交付范围与完成标准

交付 Anthropic 启发的编辑式 UI 设计资产：共用原则、语义 tokens、可复用组件、任务页面范例、中英文 PDF 规则、可操作样册与接入说明。颜色可变，布局服务任务。它是本地 vanilla JavaScript 设计系统 v1；不默认包含所有未来组件、React 包、真实 Agent、数据检索、后端或部署。样稿与真实规则摘录明确区分。

完成例：开发者从样册选择组件→使用显式内容/身份与语义主题组合页面→在报告、列表和任务页面中保持对象、数值、状态与来源→核对后返回原位置；换另一份报告或配色后无需复制页面逻辑。PDF 以已有获认可的中英两页版式为 v1 支持范围，长文跨页单独保留后续。

## 执行方式

每次只推进一个当前交付点，独立核查可并行。优先复用现有模块，不重画已认可页面，不扩成通用平台。程序检查与浏览器交互证据分别记录；不把程序通过称为用户视觉认可。页面开发不用付费模型，不发布、不上传。最终目标以以上 v1 完成条件为准，不能因暂缓项无限扩大循环。
