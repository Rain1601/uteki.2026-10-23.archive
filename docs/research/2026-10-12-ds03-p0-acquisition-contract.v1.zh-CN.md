## 2. 获取与资源规则

- 使用现有只读 HTTP 工具/`curl` 或人工下载，不新增产品获取器、解析器、SDK、存储/SQL/Agent 能力。临时请求批处理和清单记录仅为本次人工获取操作。
- SEC 请求由主代理统一执行，总频率不超过 2 次/秒；沿用已提供的本机私密联系身份，公开文件不保存值。IR 按各站访问限制，不绕过权限或拦截。
- 每个纳入原件三轮独立远程请求；请求/响应时间、URL、状态、失败/部分内容、缓存信息、实际字节数和 SHA-256 留存。使用非条件请求，不以本地复制或 304 替代取得原件；远端缓存可存在，不能声称三个独立源副本。
- 单请求超时 40 秒，每个逻辑请求最多一次临时网络重试。403、权限、内容/格式问题不自动重试；429 遵守 Retry-After，超出本次窗口留待后续。不拼接不同请求残稿。
- 本批次请求护栏 600 次、单文件 64 MiB、总取得字节 512 MiB；接近护栏停止相应获取并记录剩余目录，不删除分母。用于限制资源，不是业务完整性标准。
- 只用免费公开源和经确认无新增收费的既有合法专业权限；Key 存在不等于套餐/增量费用已确认。无权限列未测，不注册、采购、联系供应商、调用模型或访问内部公司系统。

## 3. 必须分别报告的验收

| 项目 | 标准 |
|---|---|
| 原件目录/取得 | 应取文件、附件/引用全列，逐件真实类型、发行人/form/期间、来源时间、关系和 hash 核验；失败、待披露、不适用分别记 |
| 全量事实目录 | 原件独立精读；全部财务主表/比较列、OCI/权益、分部、附注表格与正文定量事实、所选补充披露及必要条件纳入分母；未审部分仍待验 |
| 专业覆盖 | 原始返回同公司/报告/期间/版本，逐项覆盖、含义、精确出处与许可核对；未映射/缺失/冲突单列，不用其他项抵消 |
| 版本 | original/recast/真正错误更正分开；截至 cutoff 不引用未来版；公开披露 PIT 与供应商实际可用时间 PIT 分开 |
| 重复获取 | 首次成功/重试恢复/未取分别计数，三次记录均真实远程取得；不推导长期稳定 |
| 派生与生产链 | 单季/YTD、时点、周数和币种语义核对；不称 SQL、计算公式或 Agent 已实现/通过 |

离线事实清单/问题/参考答案在原件取得并精读后、对应对账/评测前分别封存；不进入生产 Agent 的选章/取材上下文。原始证据留 `output/ds03-p0-20261012-r1/` 本机私密包，公开文档只保存可公开目录/状态/证据身份。
