## 最小性与来源

两张表服务不同语义：年度金额和季度价格费用说明／年末授权余额，均有必要。1158 的 290 字符执行方式及无到期日说明，与 367 存在重复；可继续精简，但内容仍与授权范围直接相关，没有跨主题扩展。因此本次判“有界充分”，不判最优压缩。此前 v3 的 reviewer 要求删这段，本轮 reviewer 视为短小支持材料；这是审阅尺度差异，不影响事实支持，已显式记录。

10 段正文、10 条引用及字符范围均匹配原始 HTML DOM。两张表的全部单元格（含空格位、跨行跨列）与原件网格一致。原件、数据集所有文件、query／review manifest、审阅输入与 packet 哈希一致。

调用方只给问题、范围、数据集、目的及限制；系统模型独立完成 plan、阅读、选择。本次 Codex 只在封存后核验，未参与运行选材，也未调用 API 或修改材料。
