当前前台以 **Uteki 投资机构总览** 为首页，后台在另一处设计。总览上方同时比较多个 Agent 与基准，下方一次展示一个 Agent 的 Portfolio 持仓与含现金配置图。用户已允许明确标注的模拟数据；首页及 Agent 详情使用独立、版本化的设计样本，不是实盘或回测。首页采用各 Agent 的独立曲线，不合成一个机构整体收益；原 v1 机构组合样本仍保留，当前展示使用 v2。公司报告卡片与多 Agent 切换方案留待后续。

点击曲线、图例或组合旁的方形缩略卡片，均切换到同一 Agent 的持仓。缩略列上下按钮与局部方向键提供手动切换，不自动轮播；悬停不切组合。收益期间同步更新所有曲线，持仓始终为标注日期的当前快照。配置图色块与持仓列表支持悬停 / 键盘预览、点击固定与重复取消，显示对应占比和市值。点击公司直接进入该 Agent 的公司报告；没有对应报告时明确显示缺口，多候选无唯一主报告时先选择。Agent 详情入口保持。返回首页保留会话内 Agent、期间和配置选择。空 URL 打开具名机构演示入口，既有深链接保持。前台仅回看模拟操作记录，没有下单能力。Agent 详情进入概览，历史 holdings 地址兼容进入操作历史。

2026-09-30 更新：公司和 Managers 使用同一个工作台。悬停左侧实体行后，内容目录在旁边独立浮出；也可以点击目录按钮，或用键盘打开。悬停只预览目录，不改变选中实体或正文。点击具体目录项才导航。移入菜单会保持展开，离开后延迟收起，Escape 可关闭目录。Managers 不再跳往结构稿。两种实体记住最近打开的页面；报告阅读保留进入时的实体视角。

公司与 Manager 结构是三层：最左工作台导航（机构总览 / 公司 / Managers）→ 中间对象列表 → 右侧内容。机构首页省去中间索引，曲线和组合直接使用完整主内容区。Hover 最左窄图标栏后展开导航文字，并平滑推动列表与正文；离开后收回。对象列表始终可见，搜索和具体公司 / Manager 都保留在列表中。全局导航另有点击开关与键盘入口，没有固定按钮；临时展开状态不保存，旧侧栏偏好不会隐藏对象名单。实体的悬停内容目录继续独立浮出。

公司右侧现有常驻栏目，可以直接在概览、研究报告、资料与数据、关注点间切换。公司概览左侧保留四个栏目标签与数量，右侧只展开一个摘要；悬停约 140ms、点击、前后按钮或标签上的方向键均可手动切换，不自动轮播。快速经过取消切换，移到正文保持内容，每家公司在会话内记住所选栏目。每块展示状态和最多两条近况，详情通过完整入口查看；消息式提示不代表未读。正常桌面以一屏摘要为目标，小窗口或详情保留原生滚动。

2026-10-01 进一步统一公司栏目：研究报告以按 Manager 分组的左目录选择右侧全文；资料与数据以证据条目选择来源详情；关注点以未决问题选择变化及对应报告。三类长内容点击选择，避免 hover 打断阅读。初次进入无预选内容；选中状态按公司与栏目在会话内保留。顶部工具栏、公司标识与栏目区压缩留白，正文获得更多纵向空间。

## 2026-10-04：研究覆盖按关注阶段分类

研究覆盖仅展示该 Manager 明确登记的关注关系，桌面按「当前关注 / 历史关注 / 未来关注」三组并排：当前显示持续关注的问题与开始时间；历史显示原关注期间及保留报告；未来显示明确的计划原因与加入时间，不伪造开工或完成日期。没有任何关注记录的公司不进入这三组；不因属于公司目录、已有持仓或尚未有报告而自动补齐。

具名演示清单为 `uteki-manager-focus-ui-2026-09-30 / v1`，独立于原 catalog 和组合。North：Alphabet 当前、Microsoft 历史、Arista 计划；Field：NVIDIA 当前、Alphabet 历史、Eaton 计划。此分类用于前台体验，保持模拟标记，不代表真实任务或投资动作。历史公司保留该 Manager 的精确报告入口；计划公司可尚无报告，但不提供空的报告按钮。

导航覆盖总数、标题当前关注数及上下文来自同一清单。报告筛选只包含该 Manager 确有产出的公司；概览研究表移除旧 coverage 自动生成的无报告占位行，保留实际问题和已有产出。未连接关注来源与已连接的空清单分别表达，各分类无数据时留明确空状态。

## 2026-10-04：Manager 的紧凑工作台

沿用原工作台和六家公司，只调整 Manager 右侧内容：

- 研究报告：公司筛选加产出表格，每页最多 8 份独立报告。只读现有正式版本，不把历史版本重复算作新报告。

研究条目来自既有未决问题和正式报告；不再从没有报告的覆盖关系生成占位事项，也不伪造任务执行状态。待复核报告既属于已发布产物，也属于待跟进；两种筛选有意允许重叠。买卖来自机构事件轴的同一独立模拟样本，不反推成交价格或数量，也不用于组合记账。

## 评审路径

本轮 2026-10-04：Portfolio 底部提供「经典 / 明快 / 宝石 / 活力」四套鲜明分类色卡，点击原位更新饼图、持仓色标和比例条，并在本机保存选择。现金为中性灰，明暗主题分别配色。用户已选定「明快」，现为默认推荐配色，不再绑定雨滴的雾蓝色；色卡中的小饼图使用当前 Agent 的实际模拟持仓比例。

选中 Agent 的买卖标记（公司 icon + B / S）贴在该 Agent 收益曲线的对应日期上，报告（R）保留在下方事件轨道。曲线与交易标记使用同一日期坐标和收益比例尺；标记位置表示组合收益，不是成交价。相邻交易过密时按显示宽度合并，锚点保留组内最早真实事件日，浮层逐条显示准确日期。交易与报告不混组；报告独立支持自动 / 日 / 周 / 月聚合（45 天内日、120 天内周、更长月）。类型筛选原位更新；只看买入或卖出时收起下方报告轨道。点击标记打开紧凑浮层，不挤压曲线；可前后翻看同组事件，点外部、再次点标记或 Escape 关闭。报告入口保持作者、公司、报告 ID 和明确版本。

事件采用独立具名样本 `uteki-investment-events-ui-2026-09-30 / v1`（North 22 条、Field 19 条），没有从当前持仓或收益反推，也不构成可核算交易账本。报告日期来自已有演示报告版本；原组合 v1/v2 不变。参考 [TradingView 成交标记](https://www.tradingview.com/support/solutions/43000763371-execution-marks/)的密集合并和[时间轴标记](https://www.tradingview.com/charting-library-docs/latest/ui_elements/Marks/)的图标与详情机制；当前使用自有轻量渲染，没有接入 TradingView 图表 SDK。

双击曲线、图例或缩略卡中的 Agent，或点击「展开持仓」，可在主区域查看该 Agent 的模拟持仓演变。单击仍立即选择 Agent；切换时保留可双击节点。展开暂时收起当前组合区域，上方 Agent 与期间选择保持；返回恢复原组合、配置选择与阅读位置。

持仓时间轴改为日期节点与公司占比表：顶部每个明确记录日期带一条 100% 迷你配置条；点击后，下方逐公司展示 Logo、当时占比、较上次已记录日期的百分点变化，以及同一纵轴范围的小趋势图。日期按钮支持左右方向键、Home / End，悬停不切换。公司与饼图共色，现金灰色，零占比保留；首条记录没有前序比较。North / Field 各 16 个独立快照保持原样。趋势圆点为确切记录，虚线仅辅助阅读；不推导连续观测、交易或持有区间。个股涨幅、收益贡献尚未实现。

## 本轮边界

样本中的事件数字不是未读数，证据数不是原始材料份数。持续跟踪展示已有研究的未决问题，没有运行中的自动任务。Agent 模拟持仓、研究覆盖与买卖样本分离；操作历史只读取明确选定的事件样本。未接入真实账户、实时信息、结构化数据查询、模型、交易或版本比较。

`model.mjs` 只接受明确的机构、公司或 Manager 作用域；报告路由要求明确公司、报告与版本，Manager 视角还需核对报告作者。空 URL 的入口由具名 `INSTITUTION_DEMO_SCOPE` 提供；首次切入公司 / Manager 仍由对应演示配置指定，不是查询的缺省回退。历史版本不会自动提升为当前版本。证据引用校验公司与所选版本。

- `style.css`：独立视觉样式，不影响原页面。
