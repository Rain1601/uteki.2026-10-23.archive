## 此前真实运行与角色快照

本次核对当前源码、六轮真实运行的结果与证据，以及历史实验记录。Data Agent 已处理真实材料；最近六轮已结束，本轮未启动新的模型调用。持续数据处理及投资 manager 尚无完整链路验收结果。这里的 Agent 指 Uteki 产品角色，不包括帮助开发代码的 Codex 子任务。

数据下载、文档解析、索引、DuckDB 查询、注册公式计算、来源/哈希校验、成本记账主要是确定性工具与代码，并不是每一步各有一个独立 LLM Agent。模型决定取证动作，工具执行并留下可核查结果。

当前真实调用链：`CompanyDataCoordinator.query → AutonomousDataAgent（Planner）→ delegate → AutonomousDataAgent（Worker）→ 主角色核验`。这两个角色属于同一个 Data Agent 的任务分工，不能当成两位不同投资风格的 manager。

## 数据实际处理到了哪里

最近六轮输入是已冻结的 Alphabet FY2025 10-K 和候选数据集。模型自主查询 2024、2025 年经营现金流与现金购建固定资产支出、读取原文表格及单位，并检索资本开支用途。六轮没有重新抓取数据或启动全量模型抽取。数据集、候选状态和历史运行均保留。

四项财务金额、期间、单位和原表交付已有独立复核通过的实例。用途分类仍漏项，主子角色也有重复动作及收尾失败。因此尚不能称为完整、稳定的数据研究闭环。[六轮实测记录](../experiments/architecture_baseline/2026-09-29-deepseek-mixed-v1/README.md)

## 本轮离线修复与验证

已增加 `source_answer` 要求及 `answer` 动作：每条候选结论附期间语境和本角色实际读过的逐字原文，按创建要求时固定的来源与 scope 校验。只有相关段落、没有提交回答时不能完成；部分回答需保留未解决问题，最终状态为 partial。`claimed_complete` 仍是模型自报，`semantic_completeness` 保持 `not_evaluated`。

候选回答在后续读取时持续可见，旧版本留档，Worker 摘要只投影当前有效版本。首次有效覆盖状态变化可计为进展；纯改写或重复切换不能持续重置无进展限制。原 `source_evidence` 保留“原文交付”的用途，叙述问题使用新要求。未新增独立投资 Agent，也未自动采纳事实。

本轮实际离线结果：

- 新增 9 个合成数据反例通过，覆盖没有回答、未读/伪造/跨来源引用、Worker 隔离、旧 scope、新上下文挤出原文后答案仍可见、部分回答修订和重复改写。
- 既有 runtime、分页、原文与 Worker 五个模块 72 项通过；公司流水线与模型协调器两个模块 19 项通过。
- SDK 适配 25 项通过，包含用 HTTP mock 验证 partial 输出在纠错后继续保留未决问题，不冒报完成。

共 125 项离线检查，未执行全仓回归，未调用真实模型。这些检查证明新的回答与引用契约按预期执行，尚未证明模型能完整找到分类、准确解释期间，或已解决真实 Worker 的收尾问题。六轮历史产物未修改。
