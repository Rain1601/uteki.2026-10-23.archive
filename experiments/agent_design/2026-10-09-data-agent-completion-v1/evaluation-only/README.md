这里仅供 **Codex 在运行完成后核查产物**。禁止生产代码、Skill、Data/Analysis/Reviewer prompt 读取或传入这些答案；也不能用它代替运行时 Agent 生成 requirements、搜索词或选块。

[expected-support.json](expected-support.json) 覆盖 `../cases.json` 的六个问题。每题记录必要语义、一个已核对的出处组合、可替代位置及条件性要求；**不是强制模型选择这些 block，也不要求唯一检索路径**。其他同一冻结原件中的直接证据同样可以通过。

本次只读 `../datasets/msft` 与 `../datasets/googl` 的真实 HTML 和冻结 v0.1.11 解析块。重新计算原件 SHA-256，与 sources 元数据一致；对 84 个引用位置重新解析原 HTML，核对唯一 DOM 定位、规范化全文和字符切片。所用表格另外比对原 DOM 重建的完整单元格结构。检查前后数据集文件 hash 集合一致。没有模型调用、网络请求或数据集修改。

验收应分别检查：

1. 引用能否在冻结原件恢复，字段/单元格/期间/主体/单位是否一致。
2. 最终交付是否覆盖问题，必要脚注及列表是否齐全；不要把业务主类与所有产品强行等同。
3. Analysis 结论是否只使用交付材料，缺口是否明确。存在原文不代表语义一定支撑结论。
4. 是否保持系统 Agent 独立获取；此文件不能进入运行输入。实际文件加载轨迹仍须由最终运行审计确认。

一个重要限定：Alphabet 年度回购表 1155 的脚注 1156–1157 是“包含未结算回购”；费用说明在 Q4 表 366 的平均每股价格列及脚注 368。它仅明确这些平均价格包含回购相关成本，**不能扩大解释为全年回购总额已明确包含或排除消费税/手续费**。如问题要求该全年口径，保留未明确披露的缺口。

六题是现有两家公司、两份冻结报告的调试验收；并非新公司盲测、独立模型对照或完整解析质量证明。此清单在实现后建立；不得将其描述为预先冻结的 held-out benchmark。条件性保护项只在最终报告作出对应主张时适用。文件内金额和公司答案只属于离线评测资料。
