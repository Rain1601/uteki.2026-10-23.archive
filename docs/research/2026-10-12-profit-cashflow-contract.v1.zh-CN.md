## 1. 利润与现金流口径

| 项目 | 已冻结规则 |
|---|---|
| 对象/范围 | 一家美股US GAAP非金融发行人A的合并实际财务；A/B后续从DS-02已有公司组中选择，不扩大公司列表。分部、预测、pro forma与公司整体实际值分开 |
| 净利润NI | 使用现金流量表调节起点的净利润，并与利润表核对；母公司归属/含非控制性权益、持续经营/整体差异必须记录及调节。找不到一致口径时留缺口，不能换成营业利润或Adjusted Net Income |
| 经营现金流CFO | 使用合并现金流量表的经营活动现金净额，保留原始值、符号、真实期间与范围；现金余额变化、融资现金流不替代CFO |
| 调节桥 | 原表NI起点＋全部可加调节项＝CFO。项目保留原名、金额、符号、期间及必要脚注；小计与其子项不重复相加，不猜值补平。营运资金以现金流量表披露的变动为主，资产负债表简单相减不替代 |
| 再投资P | 单列PP&E现金购置支出，支出按正向金额表达并记录原符号及转换依据；不能无条件取绝对值。净额购置、资产出售、融资租赁/非现金投入、资本化软件等分别保留；维护/增长资本开支没有依据时保持未知 |
| 现金差额与FCF | 计算`CFO－P`，明确命名为“经营现金流减PP&E现金购置支出”。公司FCF另取公司定义、调整项及调节表，两者不自动等同；不将差额解释成所有者盈余或可自由分配现金 |
| 单位/币种 | 原值、数量级和币种保存；只对同公司、同口径、同币种且兼容维度的值计算。单位可按明确比例换算，币种变化不能默认汇率转换或默认USD |
| 判断边界 | 不预设利润一定增长；实际不增长须纠正前提。历史比率、非现金加回或正现金差额不能单独证明未来可持续。Data返回证据/限制，Analysis负责条件、反证和判断 |

**计算规则**：相邻年度差额=`本期－上期`；同比=`(本期－上期)/上期×100%`，仅在连续完整财年、业务口径可比且上期为正时展示。现金转化率=`CFO/NI×100%`，仅NI为正时作为描述指标；NI零/负时不计算该指标，返回数值、差额与限制。52/53周、范围变化等保留说明，不擅自标准化为等长期间。

金额计算使用原披露精度下的十进制值，最终金额按选定显示单位展示，百分比保留两位小数、ROUND_HALF_EVEN；中间值不提前舍入，记录输入事实ID、公式版本与显示规则。调节残差=`NI＋Σ带符号可加调整项－CFO`；容差由各输入及CFO的已核验舍入误差上界相加确定，实际原件包冻结时填值。精度/舍入依据不明时留待核验，不先给任意容差或见到残差后放宽。

FCF定义及限制依据：[SEC Non-GAAP说明，Question 102.07](https://www.sec.gov/rules-regulations/staff-guidance/corporation-finance-interpretations/non-gaap-financial-measures)。本契约固定的是研究口径，不把公司不同FCF改写成统一披露事实。

## 2. 三年观察与T0/T1规则

沿用DS-02的FY2025历史基准，**固定FY2023、FY2024、FY2025三个已完成财年**。这是历史验证窗口，不称截至今天的最新三年；按发行人实际起止日/周数实例化，不假定自然年或365天。T1不将窗口滚动为FY2024–FY2026；新季度/新财年的信息单列用于更新判断，不拼进原年度序列。

| 项目 | 已冻结规则；具体时刻待官方元数据绑定 |
|---|---|
| T0 | A的原始FY2025 10-K确认公开后，下一个UTC日的00:00:00。先核对公开时间/时区，不能用下载时间代替；若日级记录不足以确定UTC公开日，则T0待核验 |
| T1 | T0之后第一个公开的定期10-Q确认公开后，下一个UTC日的00:00:00；必须T1>T0，且不晚于DS-02截止日`2026-10-12T00:00:00Z`。若没有合格后续材料，更新阶段未就绪，不伪造时刻 |
| 可知范围 | 原件及所用事实/解释须有证据表明在对应截止日已公开；日期精度不足且可能跨截止日的项为“时间待核验”，不作为确定可知事实。未来数值/正文/预览不得进入历史模型输入，最终不引用不等于未泄漏 |
| 数列版本 | 默认“截至该时点可用的最新可比披露口径”；优先选同一版合并报表的三年比较列，缺期补兼容原件并记版本。重编后比较值可在允许截止日采用，但原列报继续保留；不混合无法核对的原列报/重列值制造一条趋势 |
| 修订关系 | 原列报、分部/分类重编与真正错误更正分别标注；/A或later filing不自动意味着所有事实重列。按原件说明及被影响的指标/期间认定，不整体替换无关事实 |
| T1交付 | 原三年数列有更新则另存并给逐项差异/理由/ref；没有则明确未改变。另列新季度/解释/指引变化及受影响判断。T0输入、证据、计算和报告保持可复现；获取失败不记“无变化” |
| API历史值 | 当前CompanyFacts/供应商响应不是历史快照本身；按允许accession、事实期间和原件版本核对。原始响应保存，工具筛出合法范围内事实，整份混有未来数据的JSON不上送模型 |

## 4. 内容验收标准

独立按原件建立具体事实/条件、等价出处、可选/冗余清单，在对应执行前封存；本轮只冻结以下业务判据，不编造尚未读到的数值或块ID。

| 维度 | 固定通过条件 |
|---|---|
| 基础数值/调节 | 三年NI/CFO/P共九个基础值及实际期间、单位、口径、版本全部有精确依据；口径差异的额外调节项保留。三年CFO调节段的全部可加披露项目/必要条件覆盖，残差满足事前据原件确定的容差，未知不补零 |
| 必需信息与ref | 已冻结的原件核验清单覆盖100%，公司/期间/单位/维度/版本/引用错误为零。表格引用定位到实际行列/单元格及必要表头/脚注，正文到对应原句；文件链接、预览、磁盘保存、引用存在或模型自审不能单独证明充分 |
| 解释/可持续性 | 交付历史转化、主要驱动、延续或逆转的条件、已发现反证及未知；事实、管理层观点/指引和分析假设分开。无足够证据则降低判断强度/请求补充，不强制得出“可持续”。数据合格不抵消分析推断错误 |
| 公司/材料/时间隔离 | 基线加三组干扰后核心事实保持；显式切换B时范围随之切换；重复不相加，GAAP/非GAAP与不同FCF不混用，T0无未来正文/预览输入。A缺项/B有值必须保留A缺口；年度、YTD、单季与实际/指引不混算 |
| 版本更新 | T1正确区分新增期间、旧期间改列/更正、定义/解释变化、无变化及获取失败；变化可关联T0证据/判断。旧报告及原ref仍可复现；没有真实更正材料，真实更正验收不勾完 |
| 聚焦与用量 | 按当前可交付的最小原块/表格粒度检查，无独立无关业务段落或重复披露正文；必要定义/单位/条件不算噪声。块内无法安全裁剪的冗余单列为粒度限制。记录有效占比、峰值/累计模型输入、唯一原文量、调用/耗时/费用；不靠删必要证据省token |

报告不要求统一措辞或唯一观点，但每个判断须与证据强度一致。部分结果、正确拒绝/缺口、Query完整通过、报告片段通过分别记；错误混用不能由可选材料得分抵消。历史失败、原始/修订结果及费用保留，不看到结果后改分母/阈值。

端到端时Analysis只接收研究目标与已冻结业务范围，自主提出/调整Query；设计Query清单、gold、参考答案与精确答案块不进入运行上下文。按固定Query单独重放只能证明Query层，不追认为自主报告/追踪闭环。
