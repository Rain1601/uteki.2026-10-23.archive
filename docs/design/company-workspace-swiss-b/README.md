## 紧凑视觉方案与工作流复核

- 颜色：纸面 `#ffffff`、底层 `#f1f3f5`、文字 `#18212b`、次文字 `#5d6874`、分隔 `#dce1e6`、交互蓝 `#195bd6`。暗色使用独立石墨底与明亮文字。鲜明分类色、现金灰、原始雨滴和公司 icon 不改色。
- 字体：本地 Helvetica Neue / Helvetica / Arial 与 PingFang SC / Microsoft YaHei 回退；不下载字体。实体标题 22–23px、主要区块 16–19px、正文和表格 13–14px、辅助信息主要 12px。数字使用等宽字形；长报告保持 17px / 1.85 的阅读尺度。
- 网格：仍是全局导航、对象列表、右内容；机构页没有无意义的对象中栏。正文 24px 基线，16/20/24px 区间。组合采用缩略列 / 持仓 / 配置图的对应关系，当前持仓数字稳定右对齐。
- 层次：主要靠字体、信息对齐和必要分隔，不用整块大标题或装饰编号。保留 4–9px 的功能圆角，让选中、可点与浮层保持区别。
- 复核：瑞士风格服务于比较区间、读取占比、辨认作者和追溯证据。压缩页眉和重复包围，保留模拟身份、日期、币种、来源、空状态与报告正文。B 相较 A 降低标题与强分隔的视觉重量，不只是将卡片改成直角。
