# FY2025 10-K 获取与财务核验（Codex 独立）

核验范围：系统 v2 自主发现、获取的 Microsoft 与 Alphabet FY2025 10-K 主文，以及由这些原件重建的 v3 数据集。无模型调用，无生产答案回填。独立脚本不调用生产解析/数字归一化函数。

## 结论

- SEC submissions 在截至 2026-02-06 的指定公司、报告期、10-K/10-K/A 范围内各有一个主文，系统取得 2/2，没有漏选/多选。旧 submissions archives 的最后日期早于指定报告期，不影响本次清单完整性。
- 两份 HTTP 200、身份、完整 HTML 结尾、收到字节数、对象哈希、落库原件一致。服务器没有返回 Content-Length，不能把本地哈希冒充 SEC 官方校验和。主文之外的附件、另行引用的 proxy 等不在本次获取范围。
- 新旧原件 SHA 不同已解释：**剔除 script 元素后，原始字节完全相同**。Microsoft 外置脚本路径换值；Alphabet 新增外置脚本。正文与所有 inline facts 未改变。
- 213/213 个已标准化数值记录分别回到原始 ix:nonFraction、context、unit 核验，金额、scale、符号、USD、期间、公司、维度、事实节点及引用全部一致。同一原始 fact 重复生成记录 0；原文重复披露的同指标/期间/维度数值没有冲突。
- 原件共 3,183 个 nonFraction 数值事实，当前只标准化 6 类指标、213 条；另有 2,970 条明确 `unmapped_concept`。这些不是原文被删除，完整原文/表格仍保留。**不能因此称三张报表及附注已经完整转换为标准财务数据库。**

## 重复与完成边界

原件在 MD&A、主报表、附注重复披露同一金额，各有自己的出处，应保留发生位置。本轮确认同一 DOM 数值节点没有被重复发射；不是按金额去重，也不把相同内容从原始材料删除。后续取数须采用明确的候选选择/归并策略，不能无条件相加。

当前可确认：本次两份主文的取得、冻结，以及现有六指标的逐条数值忠实性。全量段落/表格结构和所有索引定位由另一份独立 DOM 审计覆盖。图片内部文字/图中数值未在此审计中做 OCR 或语义验收。尚未覆盖其他公司、报告类型或所有财务概念的标准化。
