## 结果

模拟 2026-01-02 开盘买入，持有到 2026-10-06 收盘。金额均为美元口径；总收益含数据商股息调整，零交易费和税费。SPY 同期为 **14.51%**。

| 组合 | 全年可排名池 500 只 | 较 SPY | 含新上市证券的 503 只池 | 较 SPY |
|---|---:|---:|---:|---:|
| 前 50 名 | 33.34% | +18.84 个百分点 | 45.22% | +30.72 个百分点 |
| 前 50% | 16.56%（250 只） | +2.05 个百分点 | 18.62%（252 只） | +4.11 个百分点 |
| 全体等权 | 11.20% | -3.31 个百分点 | 12.36% | -2.15 个百分点 |

**两列不是同一排名规则。** 严格全年池排除 SNDK、Q（2025 分拆上市）及 PSKY（合并前权益未完整核验）。补充池使用正式上市首日收盘→2025 年末的收益纳入三者，排名期长度不一。前 50 名因此换入 SNDK、换出 FOXA。这一改变让收益增加 11.88 个百分点，说明新股规则对结果很重要。不是事后将更好的规则替换为主结果。

后半组行业内命中率最高：房地产 25/31（80.65%），必需消费 25/36（69.44%），原材料 15/26（57.69%）。全体基准为 50%。这是行业分布诊断，没有另行回测“删除某些行业”的策略。

## 时间和投资口径

- 排名起点：2024-12-31 收盘；终点：2025-12-31 收盘。
- 执行：2026-01-02 开盘，排名已知，避免假定能以产生信号的同一收盘价买入。
- 初始每只投 1/N；此后权重随价格漂移，不做每日再平衡。允许碎股。
- 主体使用 Yahoo 调整收盘价；入场价为开盘价 × 当日调整收盘价 / 收盘价。
- 现金收购后现金零利息；换股后继续持有换得的股票；不因指数除名而删除原持仓。
- 价格指数同持有区间为 13.68%；标准 12/31 收盘起算 YTD 为 14.22%。二者起点不同。主对照采用同区间含股息的 SPY 14.51%，不把不含股息的指数与含股息股票混作同一口径。
- 证券为计数单位，同一公司不同股类分别等权。503 只不等于 503 家公司。

## 输入与核验依据

历史集合来自 [2025-12-31 iShares 存档](https://raw.githubusercontent.com/riazarbi/sp500-scraper/main/ishares/sp500/csv/20251231.csv)，筛选 Equity，规范 BFB / BRKB 为 BF-B / BRK-B；与[同日 tidyquant](https://raw.githubusercontent.com/riazarbi/sp500-scraper/main/tidyquant/sp500/csv/20251231.csv)的 503 股集合一致。快照时间不等于持仓价格时间，未使用这些快照的 price 字段算收益。12/22 名单变更与[标普公告](https://press.spglobal.com/2025-12-05-CRH%2C-Carvana-and-Comfort-Systems-USA-Set-to-Join-S-P-500-Others-to-Join-S-P-MidCap-400-and-S-P-SmallCap-600)核对。这是公共存档研究结果，不是授权指数历史数据库认证。

批量行情为 Yahoo chart JSON；原始响应和哈希保留在 raw/、data_manifest.json、reproduction_manifest.json。下面公司行动依据保存在 config.json 对应 source 字段，并由公告逐项核对：

| 旧证券 | 2026 处理 |
|---|---|
| BK / MMC / EQR / PSKY | 分别续接 BNY / MRSH / VMRK / SKYD，同一持有权益的代码变更；EQR 为合并后的存续主体 |
| DAY | 2/4 每股 70 美元现金 |
| HOLX | 4/7 每股 76 美元现金，加不可交易、最高 3 美元或有支付权 |
| CTRA | 5/7 每股换 0.7 股 DVN |
| AVB | 8/17 每股换 2.793 股合并后 VMRK |
| EA | 8/4 每股 210 美元现金 |
| WBD | 10/6 每股 31.01666668 美元现金，含延期补偿 |

退市前 CTRA / DAY / HOLX / AVB / EA 的 OHLC 由 ChartExchange 历史表程序解析。AVB / EA 在该页的早期行情不足，2024-12-31 基点另在 supplemental_prices.json 记录两个交叉来源和人工核对事实。现金股息日期/金额在 supplemental_dividends.json；程序在除息日收盘再投资，再处理换股/现金退出。未抓取到的原始网页明确记在 supplement_sources.json，不把网页搜索核验冒充本地已保存原件。

HOLX 或有支付权主表按零估值；最高名义支付额使 500 股全体组收益至多再增约 0.0080 个百分点，前 50 名和前半组不受影响。这是估值敏感性上界，不是其市场价值或承诺支付。

## 复跑

只需 Python 3.11+，不安装数据分析库。冻结数据上的计算没有网络请求：

```sh
python3 backtest.py
python3 test_backtest.py
python3 build_report.py
```

在本目录执行。重复运行 results.json 内容确定；reproduction_manifest.json 的计算时间会更新。原始数据不被计算脚本改写。联网下载入口为 fetch_data.py 和 fetch_supplements.py；已冻结原件优先复用，不能以更新后的供应商历史数据冒充本次原始输入。重新取数应复制为新实验目录并保留新的哈希；例外事件及供数商修订需要独立核验，不是自动无限期行情维护器。

## 已完成检查与边界

6 个独立手算测试检查初始等权、不再平衡、开盘复权、损失、缺日期拒绝和奇数分半。真实数据检查包括证券唯一性、美元币种、日期、全部持有期报价完整、排名先于买入、前后半不重不漏、组合期末净值与各股回报均值一致。两套排名的明细和组别全部保留。

所有图表共用真实 results.json；报告通过生成、数值、链接及 JavaScript 语法检查；另外执行真实页面脚本的筛选逻辑，确认全部 503、前 50、AAPL 搜索、后半房地产 25 和重置结果正确；本机 HTTP 返回与成品一致。未进行浏览器视觉验收。主体复权数据未逐只独立审计所有分拆/分派调整；补充源的分红再投资与 Yahoo 调整规则可能略有差别。本次只有一个持有期，不能推出长期稳定超额收益。
