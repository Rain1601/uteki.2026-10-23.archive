# Anthropic / Claude 小型动态素材调研

观察日期：2026-10-12。范围为三张官方页面，目的是确定下一次原创组件试作的方向；本轮不实现或发布新组件，不复制官方插画素材。

## 已观察的原例与证据

1. [Claude 金融服务](https://claude.com/solutions/financial-services)：Built for finance 的储蓄罐、How finance teams use Claude 的握手、More products 的工具箱、resources 的铅笔、FAQ 的问号，均在可访问图像容器内呈现 SVG；SVG 内出现 `__lottie_element_` 标记。工具箱在可见区域的两次 DOM 采样不一致，确认有逐帧变化。在当次桌面视口，其 SVG 约 91 × 91px，配合居中的大号标题。页面上方另有 muted/loop/autoplay/playsinline 的 WebM 视频。静态楼梯 SVG 未见同类 Lottie 标记，因此不把所有插画都当作动画。
2. [Claude 产品总览](https://claude.com/product/overview)：本次 DOM 有多个 muted/loop 的 MP4 和 WebM（autoplay 属性为 false），另有具名 iframe 展示案例产物。不能从 loop 属性推断播放触发机制，未核验所有短片内容与播放周期。
3. [The missing map of the sky](https://www.anthropic.com/research/the-missing-map-of-the-sky)：文章内嵌天图的独立 HTML iframe，提供多种成像模式的对照。这是可交互图解，不应归为 GIF 或纯装饰小动图。本轮只核验嵌入方式与官方描述，未审计图解内部实现。

浏览器观察与技术判断分开：工具箱逐帧变化和 SVG/Lottie 标记是实测；其余小插画的可见对象及结构已确认，但播放触发、精确时长、帧率、离屏暂停与减少动态策略未逐一核验。仅凭外观无法确定原作者使用哪种制作软件。

## 美学分析（本项目判断）

- 小插画承担章节的视觉标点，标题与正文承担信息主体。固定插画占位使内部动画不推动排版。
- 深色轮廓、有限填色与带手绘感的形状，形成轻松但克制的语气。结构比米色配色更值得复用。
- 动作发生在物体内部：展开、组合、转动、描线、出现。无需让整页大幅位移。
- 每段只保留一个主要动态对象；先有明确静态形态，再用动作补充含义。
- 不要求跨页或分屏，符合本项目连续单页展示的偏好。

## 建议原创组件方向（未实现）

| 方向 | 实际页面位置 | 可配置内容 | 推荐机制 |
|---|---|---|---|
| 工具/资料包展开 | Agent 任务页标题或输入区 | 物件、尺寸、语义配色 | 简单 SVG + 时间线，显式播放/重播 |
| 纸张翻动与铅笔落笔 | 报告章节、笔记、空态 | 纸张内容符号、颜色 | SVG 图层位移/旋转，正文保持静止 |
| 材料汇集、对照显现 | 研究报告图解 | 真实关系、文字、配色 | 原生 SVG/DOM，滚动或主动操作驱动 |

默认建议进入视野播放一次，停在可理解的静帧；重播由用户触发，循环是显式选项。减少动态时直接展示静帧，离屏停止不必要更新。以上是我们的实现建议，不声称官方已全部采用。

技术选择：可换色的简单原创图形优先 SVG/CSS 或 Web Animations；复杂逐帧插画再选择 Lottie；有纸感纹理或复杂合成时可选短视频，但视频换色和夜间适配通常需要独立资源。动效不能伪造 Agent 进度或证据完成状态。

本轮交付为原例分类、DOM 证据和组件建议；下一小步建议试作三种原创小插画，放进现有单页布局后比较。
