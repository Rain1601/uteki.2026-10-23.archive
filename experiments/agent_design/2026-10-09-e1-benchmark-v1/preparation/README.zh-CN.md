## 获取过程与修复

1. 最初 SEC 联系标识未配置，系统未发请求。旧状态保留在 `../acquisition/preflight.json`。
2. 用户提供真实联系标识后，仅保存在忽略的本地 `.env`，权限 600；公开材料未含该邮箱。
3. 受限环境 DNS 失败；批准联网后，系统发现 SEC 被本机代理解析为 `198.18.*` 的 fake IP，原公共地址检查拒绝请求。
4. 为已配置的本机 HTTP CONNECT 代理增加显式 transport 模式。代理地址必须为无凭据的 loopback IP 和明确端口；目标只能是明确列出的 SEC 系统域名。HTTPS 证书与原域名校验、重定向目标约束、请求/大小/重试限制保留。默认直连仍拒绝私网及 fake IP；没有给 `198.18.*` 开白名单。
5. 第一次真实成功运行 `20261008T205046-a663c12323dd`：3 次 HTTP 请求，发现并下载两份原件，0 获取缺口。
6. 相同配置第二次运行 `20261008T205136-4d90b9bab90e`：1 次目录请求，两份原件均 `reused_verified`，ID、哈希、对象路径不变。

transport 配置经统一 `_configuration` 验证；CLI acquire/prepare、注册公司 profile 与 CompanyQueryInput.company_config 均传递完整配置字典，无字段过滤丢失。CLI 路径已做代理测试。CompanyQueryInput 的公开 schema 中 company_config 原本就是字典，没有声称新建了强类型公司配置 schema。直接下载与注入 fixture 路径保持区分。

## 实际工程检查

双年材料包含 2,951 个原文块、204 条候选指标记录。记录为披露出现次数，不是 204 个唯一财务事实；完整财务结构化和语义覆盖尚未因此通过。

- 重复 source_id 输入被拒绝，未发布一个重复计数的数据集。
- 检查跨报告相同实体/指标/事实期间的 48 组候选记录：29 组值等价，19 组存在差异。系统保留所有原始出现位置；等价组返回 matched，差异组返回 ambiguous。
- 显式限定每份原件后，查询没有带出另一原件的记录。
- 截止 2024-12-31 的目录仅返回 FY2024 原件，排除 FY2025 后见材料。
- 上述是确定性查询与数据检查，不是 Agent 自主推理验收。模型仍需通过独立题集证明会选择正确披露版本、取得差异说明，并控制冗余。

本次 FY2025 下载与旧冻结原件 raw hash 不同。独立比较显示，移除 script 元素后 DOM 相同，差异仅为传输附加脚本。两份原件仍分别保留原始哈希，没有规范化重写。不能把这样的字节变化直接认定为财务重述。

详细结果见 `foundation-verification.json`；相关获取、恢复、公司配置与代理边界测试见 `transport-regression.txt`。测试包括环境 NO_PROXY 不覆盖显式代理、协议/域名/IP 重定向拒绝、SEC 目标子集限制与默认 DNS 拒绝行为。
