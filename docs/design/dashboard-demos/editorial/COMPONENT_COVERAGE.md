## 定制契约

1. 版式与组件身份保持稳定。通过语义 tokens 切换背景、表面、正文、次级文字、分隔线与强调色；状态色与图表序列独立配置。
2. 字体按展示标题、阅读正文、控件、结构化数字四个角色设置。中英文各有可用回退；表格、轴标签、单位和日期保持清楚的无衬线与等宽数字。
3. 组件公开内容、尺寸变体与布局槽位，不暴露一套随页面变化的零散 CSS 覆盖。主题切换不修改业务数据、筛选、选择、来源或范围。
4. 数据表格声明列类型、单位、格式与缺失状态。图表声明系列身份、期间、单位和来源；不通过装饰改动负值、分母或真实数值。
5. PDF 打印样例使用相同内容模型，但有单独的分页与字体规则。HTML 预览、打印样稿、成功导出和生产导出能力分别记录。
