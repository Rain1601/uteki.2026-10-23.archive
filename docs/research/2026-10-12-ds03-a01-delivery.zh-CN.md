# DS-03-A01 官网材料获取：有限交付

模型从官方根站发现链接、选择材料，工具下载并归档的入口已实现。DeepSeek 当次取得台积电和微软 FY2025 各一件 HTML 原件，Codex 独立原件与发现链检查通过。两例不证明长期稳定、任意公司支持或年度财务包完整；首次发布日期未知，材料不自动进入历史截止日证据集。旧 T01 验收未改变。

## 现象、机制与入口

原 Data Agent `acquire` 仅接受 `filing_selection`，官网获取依赖程序目录规则。现增加有界官网会话：模型从根起点调用 `browse`，只能访问本次工具返回的链接；随后 `download` 提交原文证据和选择理由。共同层仍负责请求限额、最多一次临时重试、错误正文、冷却、hash 对象及版本记录。SEC 原路径保留。

可调用入口：`CompanyDataCoordinator.acquire_official(config, task, output=..., model_config=..., credential_root=...)`，不要求已有查询数据集。已有 query 路径也支持 `acquire.arguments.official`，须由调用方提供 `config.official_discovery`。模型使用现有 `SdkAutonomousPlanner`、`AutonomousDecision` 和同一 RunBudget。网页内容仅为不可信观察数据。

输入/动作见[冻结契约](2026-10-12-ds03-a01-contract.v1.zh-CN.md)，完整显式样本配置及调用见[运行器](../../experiments/agent_design/2026-10-12-ds03-a01/run.py)。已有运行目录不可覆盖，运行器不是无条件重跑指令。

实现：[协调入口](../../src/uteki/agents/data_query/coordinator.py)、[模型执行模式](../../src/uteki/agents/data_query/official_acquisition.py)、[官网工具](../../src/uteki/infrastructure/document_sources/official_discovery.py)、[共同传输与归档](../../src/uteki/infrastructure/document_sources/company_acquisition.py)。官方主机精确限定、跳转逐次检查，连接固定到已核验公共 IP，TLS 校验原主机，不使用环境代理。未支持公司身份发现、全网搜索、JS 执行、PDF/OCR/PPT；当前类型词面检查限英文 HTML 年报/全年业绩。
