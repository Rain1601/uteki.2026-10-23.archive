# Codex 调用前方案：先固定财报解析产物

2026-10-07，顾问调用前草案。当前任务是定义并展示稳定的解析输出，不将两条问答案例当作解析完整性的替代验收。

## 结论

保留 Uteki 编排、模型调用、预算、工具、日志、产物和证据身份。解析分为确定性原文层、导航层与模型业务加工层。原文层由程序处理；Sonnet 5.5 执行业务加工，Opus 5.5 可做需要的规划/评审。角色选择不意味着每个任务都必须调用两个模型。

先建立一个版本化的 SEC HTML 解析包。原件不可变，规范化块及表格可精确重放，人读文档只是这些块的确定性显示。另一种“精编文档”由模型归纳，固定字段、章节规则、证据和验收，不承诺新调用的文字逐字相同。

## 原文解析包候选

- source.json：公司、文档、来源快照、URL、原件 hash、表单类型、报告截止日、解析与导出版本、索引身份。报告截止日不是所有表格行的财务期间。调用方明确提供，并与冻结来源核对。
- blocks.jsonl：已有 SourceBlock 原文顺序、类型、规范化文本/hash、DOM、来源锚点、报告页码、样式、表格、图片引用。选择正式 materialization 的 style_signature 二元数组形式；新包独立版本，不修改旧导出。
- index.json：已有 document/part/item 树及诊断；已识别结构与缺口均保留。不是“所有标题已理解”的声明。
- anchors.json / toc.json：把内存中已有原始锚点与目录候选完整导出，不等同于已确认目录。
- assets.json：图片引用及 alt/DOM，读取状态必须明确；只有引用时不声称已抓图或 OCR。
- schemas/：每种机器对象的 JSON Schema。跨文件身份、范围和 hash 需另外验证；schema 合法不代表内容完整正确。
- document.html：确定性的标准阅读文档，来源身份、目录、诊断、块顺序、块/单元格锚点；不让模型重新改写原文。HTML 表格保留 rowspan/colspan，未知页码保持空。无自动远程加载。
- manifest.json：各文件 hash、版本和包身份。输出目录与执行时间放包外运行记录，不能让绝对路径改变规范内容。

同一原始字节、身份、显式解析版本、导出版本及运行依赖下，在两个目录完整导出，比较全部包内容 hash。AMD 10-K 与 TSMC 20-F 作真实不同公司样例；另用独立小样例测试边界。此实验出口尚未替换生产 prepare，不把它称为整个 Data Agent 已迁移。

## 业务加工产品候选

业务产品复用既有 ResearchRecord、EvidencePackage、BusinessMap 和 narrative 契约，按缺口补充；不把每一种文件扩展名视为独立数据产品。

| 类型 | 单位和内容 | 最低约束 |
|---|---|---|
| 结构化事实 | 一个主体、指标、实际期间、维度和单位下的值 | 来源值/规范值、口径、值类型、候选/核验/采用状态、根证据、转换版本；缺失不补零 |
| 精编文档 | 固定模板中的章节和可识别陈述，中英文表达共享陈述身份 | 模板/任务范围、事实/管理层观点/计算/推断区分、原片段或公式依据、覆盖与缺口；稳定渲染，模型文本重跑作语义评估 |
| 业务图 | 公司业务实体、产品/客户/赚钱方式、关系及有效时期 | 节点/关系身份、属性依据、关系方向、推断标记、原始出处；未知不编造 |
| 导航索引 | 原文结构节点、主题入口、节点摘要 | 指向原块范围，摘要只用于导航；不作为独立根证据、不重复统计事实 |
| 证据包 | 一次问题按已选公司/期间/截止日/来源范围取得的材料 | 具体块/字符/单元格与必要表头脚注，检索覆盖、未访问范围、来源血缘 |

精编文档的标准样式：身份与范围 → 原文覆盖目录 → 分节陈述（主文、数表、来源）→ 缺口及冲突 → 版本/运行信息。具体章节 ID 和覆盖清单来自显式选择的模板，不默认为所有公司套某一份财报的章节。源文档未覆盖的必需章节输出明确 gap，而不补写。

## PageIndex 分工

SEC HTML 当前已有块/表格/法定目录，先复用其树导航方法。真实 PDF 可候选复用固定版本 page_index_flash(pdf, summary=False, optimize=False) 生成物理页目录，再映射 Uteki 的块。Flash 公共结果不提供完整表格单元格或稳定原文块，不能代替解析层。

不接入其完整 chat/submit_document 执行循环；摘要/优化/重试/并发都由 Uteki 明确调度。尚未运行 PageIndex，接入成本/质量需要 PDF 实测。

## 可复现的四个验收

1. 原件与确定性解析：同输入、版本、依赖，包文件 hash 相同。
2. 输出契约与渲染：字段、章节身份、排序、证据格式稳定，格式校验通过。
3. 模型加工：多次调用核对数值、范围、关系、证据支持与覆盖；表述变化不等于事实变化。固定参数不保证完全确定性。
4. 发布复用：采用后的产物冻结 hash，重复消费读取相同版本；升级再出新版本。

本轮只做 1、2 的原文包部分及顾问评审；未宣称结构化事实、精编、业务图全链路已验收。
