# Uteki 首页 / 工作台结构稿

这是一个独立、可点击的首页结构稿，用于讨论研究对象、信息优先级与阅读流程。它不接入生产数据，不运行研究任务，也不修改已有工作台或 Logo 封版。

公司身份选自现有候选名单 `data/company_universe/v0.1-candidate/companies.json`，原名单没有修改。**全部研究结论、变化、证据、任务进展、组合、交易动作和收益均为虚构示意。** 日期、版本和收益数字也是演示内容，不能当作真实新闻、实际持仓或投资建议。Manager 仅使用“示例经理 A / B”，不映射真实经理或研究 Agent。

## 本轮确认的结构

- 每家公司有一份持续维护的主研究报告。追踪记录和专题研究围绕主报告展开；结构稿中的变化可回到具体报告与因素。
- 首页优先呈现已关注公司中原有判断的变化，再展示新公司的研究机会。
- 变化区回答：原来怎么看、新增什么证据、哪些判断获得支持或受到挑战、与持仓理由有什么关系。示意中的持仓影响是待复核的研究解释，不是调仓指令。
- 持续任务关联具体公司、主报告和因素，展示等待什么信息、近期进展与下次检查时间。它们在此页面不会实际执行。
- 自主研究与委托 Manager 是两个独立视角。Manager 区展示其示意组合、决策动作与同一展示期间的收益，不把经理动作当作用户自己的决策。

新机会公司的报告是主报告的初步研究版本。完整专题报告编辑、多版本对照、任务执行与真实收益计算尚未实现。

## 本地启动

在仓库根目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory apps
```

打开 <http://127.0.0.1:8768/attention_studio/>。页面需通过 HTTP 访问，以加载 ES modules。现有 Logo 展示页可继续使用其原端口。

## 建议讨论的交互路径

1. **从公司进入变化。** 点击关注公司的角标或公司入口，筛出该公司的变化。角标统计未读的独立变化，不累计每条证据；没有变化时呈现空状态。
2. **理解一项变化。** 打开卡片，在同一窗口内阅读原判断、新材料和研究影响，再查看证据、关联主报告或追踪任务。已读只是阅读状态，不代表接受新结论。
3. **留下自己的关注点。** 用“留待复核”收藏变化，也可选择“记下我的判断”并点击“保存笔记”。笔记最多 2,000 字。切换视角、详情或筛选时，未保存草稿保留在当前页面会话中；回到同一变化再打开笔记可继续编辑。只有显式保存后才写入本机存储，刷新页面会丢弃未保存草稿。“取消”会丢弃该条草稿，保留此前已保存的笔记。收藏、已读与笔记不写入研究报告、不采纳证据，也不提交任何投资动作。
4. **查看委托组合。** 切换示例经理，查看其持仓、现金、收益期间和动作。点击持仓公司会回到“我的研究”视角，选中该公司并打开其主报告；“计划中”和“已执行”只表示示例数据中的动作状态。
5. **重新演示。** 使用“重置演示”清除本结构稿的已读、收藏、已保存笔记及会话草稿，恢复研究区的全部公司与全部变化筛选。当前界面语言保留，不会清除其他应用的数据。

语言、已读、收藏与已保存笔记使用独立的 `localStorage` 键 `uteki:attention-prototype:v1`，不会写入其他命名空间。浏览器本机状态不跨设备同步；更换访问来源或端口会得到独立存储。本机存储不可用时，操作只保留在当前会话；收藏、保存笔记和重置操作会提示这一限制。结构稿不提供真实新闻推送、交易执行或模型分析。

## 代码检查

从仓库根目录运行：

```sh
node --check apps/attention_studio/data.mjs
node --check apps/attention_studio/model.mjs
node --check apps/attention_studio/app.mjs
node --test apps/attention_studio/model.test.mjs
```

模型测试覆盖一公司一主报告、变化排序与筛选、独立的已读和收藏状态、角标去重、空状态、未知范围拒绝、公司—报告—因素—任务—证据的引用范围，以及经理持仓加现金合计 100%。测试包含独立合成数据，避免仅验证某一家演示公司。

这些是数据结构与选择逻辑检查，不等同于真实研究或投资结果，也不代表浏览器视觉验收。页面美感、阅读密度与交互取舍留待用户通过结构稿确认。
