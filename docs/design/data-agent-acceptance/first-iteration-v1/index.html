处理过程 Processing

这是拟议的完整流程；各步已有能力与缺口分别列明。

  1. 01 获取并冻结程序：原件、身份、版本、哈希。已有年度材料；新增角色与渠道覆盖待补。
  2. 02 保真拆分程序：段落、表格、单元格、图片引用。HTML 已有；图片未 OCR。
  3. 03 标记噪声，核对目录程序为主：导航、正文、表格上下文、位置。保留原件；重复导航与 TSMC Item 仍有缺口。
  4. 04 按产物加工模型：抽取事实、忠实精编、业务关系；程序负责范围和执行。历史局部提取已跑，完整产物未齐。
  5. 05 分层核验程序：Schema、引用、单位、范围；内容核验：真实性、限定、遗漏。结构通过不等于内容正确。
  6. 06 按问题查找模型选数据与工具，系统执行和回读；回答带片段、范围和缺口。独立评价 Query 质量。
