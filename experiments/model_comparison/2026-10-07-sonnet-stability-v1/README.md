# Sonnet 固定配置重复检查

本轮已完成，结论与逐次明细见 [RESULTS.zh-CN.md](RESULTS.zh-CN.md)。

用户要求检查当前 Sonnet 配置能否稳定复现。本轮保持 AIHubMix 的 `claude-sonnet-5-5`、`thinking.type=adaptive`、`output_config.effort=high`、`max_tokens=8000`、`stream=false`。不发送 temperature、top_p、top_k、seed；不增加对话历史、工具、重试或修复请求。

## 输入与预登记

复用上一轮的 AMD FY2023 五个冻结来源块。两项任务分别为六条现金流事实提取，以及两条经营现金流事实加同比变化说明。每题已有两次 Sonnet 请求，本轮交替串行新增三次，形成每题五次。任务、提示词、JSON 约定不作任何修改；实际请求正文和配置快照须与本题旧请求相等。

[plan.json](plan.json) 先固定输入、调用顺序和判断规则；[execution-pin.json](execution-pin.json) 在首次新调用前固定执行器、评分程序、材料和旧结果哈希。旧材料和历史评分不覆盖。新结果放在各自的 `runs/<case>` 目录。

## 判断标准

- 请求是否独立成功：HTTP、结束原因、响应 ID、用量、耗时与费用逐次保存。
- 数值是否正确且稳定：检查值、符号、期间、单位、币种、原文行列、引文；另比较规范化事实哈希。相同答案不自动等于正确。
- 文本是否一致：分别报告原始文本、JSON、排序与空白规范化后的不同版本数。
- 结论是否可靠：同一位独立 Codex 评审将本轮及旧轮共十份答案匿名重评，隐藏重复次数和新旧身份。沿用五维 0–2 分规则；总分至少 8、证据忠实度 2、期间与因果区分至少 1，且无无依据预测或建议，才通过定性检查。单个模型评审不能替代人工标准答案。
- 保留旧百分比容差检查；题目未指定小数位是已知规则缺口。合理舍入若被该门槛拒绝，须明确区别于算错。不能为了通过测试而修改模型输入或事后换门槛。

## 费用与停止条件

新增调用共用一个账本，估算额度 0.75 美元。逐次先保守预留再派发，完成后按供应商返回用量结算；无自动重试。六次最坏情况预留总和约 0.811122 美元，高于额度，因此额度不足时停止后续调用，不保证六次在最坏情况下均可完成。未知用量、未结束请求、失败或格式无效也停止继续派发。

估算沿用已冻结价目：输入 2 美元/百万 token，输出 10 美元/百万 token，不扣缓存折扣，不代表账单。2026-10-07 搜索再次核对到 [AIHubMix 官方页面](https://preview.aihubmix.com/model/claude-sonnet-5-5) 相同价格。

## 解释边界

这是已知旧结果之后增加的重复试验。两题仍使用同一公司同一小节，仅含六个独立来源事实。每题五次不能建立生产稳定率，也不能证明跨公司、20-F 或完整报告能力。固定参数不等于锁定供应商权重、路由和硬件；服务器内部实际执行的配置未独立回显。

运行入口 `run_case.py --ordinal N` 每次只派发一次；`evaluate.py --output <新文件>` 仅离线评分。结果登记沿用既有工作台接口，每次保留独立 Trace ID。未进行页面视觉检查。
