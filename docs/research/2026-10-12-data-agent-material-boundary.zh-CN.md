# Data Agent 材料边界 · 讨论版 v0.1

日期：2026-10-12。当前只明确材料分工，不接入 FMP、不运行 Agent、不进入具体公司、不开发。范围沿用 DS-02：美股 US GAAP 非金融企业的完整财务，行情与宏观留下一阶段。

**原则：先用确定性方式取得结构化事实，再把缺失、冲突或需要语义判断的原件片段交给 Data Agent。** Data Agent 不重复抄写已有结构化三表，也不直接决定事实入库；它返回事实候选、证据和缺口，经过确定性校验后才能成为标准财务记录。

**适用边界补充（2026-10-12）**：本文规定财务材料准备/入库时的解析分工，不是Query阶段Data Agent的全部职责。Query阶段Data Agent还要判断需求与数据类型，选源，生成受约束API请求参数/查询计划或文档检索条件，调用工具并返回证据及缺口；确定性取数仍属于其能力，JSON等无需模型重新解析。[完整路径讨论稿](2026-10-12-query-evidence-plan.zh-CN.md)

## 1. 无需模型重新解析的材料

| 材料 | 默认处理方式 | 原因 |
|---|---|---|
| FMP Free/Premium 的 JSON 返回 | API适配器、Schema校验、原始响应留存 | 已是结构化数据；Agent阅读会增加成本且降低确定性 |
| SEC Submissions、CompanyFacts、CompanyConcept JSON | 确定性解析、版本和期间筛选 | 字段和事实结构明确；需要规则而非语言理解 |
| SEC iXBRL/XBRL 中可直接取得的 fact、context、unit、dimension | XBRL解析器及校验规则 | 保留原标签和上下文比模型重新读数字更可靠 |
| 结构稳定且字段明确的 CSV/XLSX | 表格解析、类型/合计/期间检查 | 能确定性处理时不调用 Agent |
| Q4、TTM和已冻结公式的派生值 | 显式计算并记录输入/公式版本 | 派生计算不能交给自由文本推理后直接入库 |

这些材料仍由工具提供给Data Agent参与Query取数、覆盖和冲突检查；确定性解析无需模型重新读一遍。

## 2. 需要 Data Agent 处理的材料

只在结构化路径不能完整表达以下内容时进入 Agent：

| 优先级 | 材料 | Agent 要提取或判断什么 | 典型财务范围 |
|---|---|---|---|
| P0 | 10-K/10-Q 的附注正文和复杂表格残差 | 原始指标、数值、单位、期间、维度、限定条件、定义及精确证据；标记未映射/冲突 | 税务、租赁、债务、承诺、SBC、养老金、收购、减值、公允价值等全部定量附注 |
| P0 | 10-K/10-Q 的分部及地区附注 | 报告分部、产品/地区分类、收入/利润/资产、公司项目和合并调节；识别分部变更与比较期重编 | F06 分部、产品、地区及调节表 |
| P0 | 8-K 财务附件与官方 earnings release | 非GAAP指标、GAAP调节、季度业绩表、指引及其期间/口径/条件 | F08 非GAAP、财务KPI、指引 |
| P0 | 公司IR财务补充材料 | SEC原件中没有或表达不完整的财务表、KPI、口径说明；与SEC事实关联去重 | supplemental workbook/PDF、季度补充表、指标定义 |
| P1 | 主表或权益/OCI中未被结构化源正确覆盖的行 | 仅处理覆盖差异清单中的缺项或冲突，不重读整张已覆盖报表 | 自定义标签、特殊归属、终止经营、权益变动、OCI |
| P1 | 财报中的关键解释段落 | 解释数值口径必需的定义、范围变化、重列原因和一次性事项 | 会计政策变化、重分类、合并范围变化 |
| 条件触发 | 图片、扫描表格和图表 | 只处理没有可替代HTML/XBRL/工作簿且包含必需财务事实的内容；先OCR，再由Agent做语义与证据核对 | 扫描附件、嵌图表格、图中必要数值 |

## 3. 本阶段不交给 Data Agent

- 行情K线、公司行动和宏观时间序列：下一阶段用专业结构化接口。
- 公司博客、产品页、新闻和第三方研报：不属于当前“完整财务”事实分母；只有未来明确的业务研究问题需要时再纳入。
- 完整电话会音频和Q&A：DS-02 未纳入首批财务核心。
- 已由结构化事实完整覆盖的整份10-K/10-Q：不为“保险”重复全文提取。
- 搜索摘要、新闻转载或聚合站内容：不能代替 SEC/IR 原件。

## 4. Agent 的输入与输出边界

Agent 输入必须包含：明确公司/报告/期间、原件及hash、待补类别或差异清单、允许使用的来源、输出Schema和资源限制。系统 Agent 可以在这些材料范围内自主定位章节、阅读、补取关联片段和修订；离线参考答案、人工选好的答案片段和预期数字不传入。

Agent 每条事实候选至少输出：

`issuer｜filing/accession或IR材料ID｜原始指标｜标准指标候选｜原始值｜单位｜期间｜维度｜版本｜限定条件｜精确证据｜提取状态｜冲突/缺口`

Agent 不直接写标准财务表。确定性环节先检查身份、期间、单位、维度、证据、合计/调节关系和重复事实；通过后才入库。无法确定的项保留原始事实并进入人工/规则复核，不能猜测映射。

## 5. 单份报告的材料路由

```text
SEC / IR 原件
      │
      ├─ 结构化接口或XBRL可完整表达 ─→ 确定性解析与校验 ─┐
      │                                                  │
      └─ 缺失、冲突、复杂表格或正文条件 ─→ Data Agent ──┤
                                                         ↓
                                          统一证据/冲突校验
                                                         ↓
                                              经核验的财务记录
```

完成标准不是 Agent “读完文件”，而是冻结材料清单中的每项事实都有一种明确状态：已取得并可追溯、未披露、不适用、来源未覆盖、解析失败或待复核。结构化数据与 Agent 结果使用同一原件分母验收。

## 6. FMP Free 在本阶段的作用

FMP Basic/Free 官方公开为 `$0/月`、`250 calls/day`，定位是测试接口和探索数据，带有限历史、端点及标的限制。先用它验证：

1. API Key与调用链能否工作；
2. 标准财务实际返回Schema、期间、空值和错误形式；
3. 免费权限具体开放哪些计划中的接口和标的；
4. 原始响应能否安全留存并与SEC事实关联；
5. 哪些缺口必须进入SEC原件或Data Agent。

Free结果只证明该免费权限下的可用性，不能外推Premium覆盖，也不能用受限标的替代完整财务验收。注册、获取Key和真实调用是下一阶段动作，本轮未执行。[FMP官方价格表](https://site.financialmodelingprep.com/pricing-plans)
