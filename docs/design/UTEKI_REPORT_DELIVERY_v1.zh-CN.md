# Uteki 正式研究报告：内容与交付标准 v1

初稿 2026-09-29；2026-09-30 同步问答决策。状态：供讨论的报告标准，尚未完成真实报告内容验收；不新增运行接口或生产页面。

已确认：Uteki 以高质量、深入且聚焦的报告作为核心交付，减少用户与 Agent 的交互。共享数据支持不同 Manager 独立判断；只做多个股、无杠杆、允许现金。公司与 Manager 入口引用同一份正式报告版本。

已确认：统一必须回答的问题，允许不同 Manager 调整论证重点、方法和篇幅。完整报告须独立可读，摘要、目录、证据和比较提供阅读帮助；核心内容不依赖追问或在多个辅助页之间拼接。

首次报告须完成核心研究与审阅才对外发布，此前显示“研究中”。已发布报告遇到可能影响核心判断的新证据时保留旧版，标注“结论待复核”、受影响部分和信息截止；新版完成后更新并保留历史。公司研究回答“是否买”，组合报告回答“买多少”，两者关联。详见[五项已确认规则](README.md)。

已确认正式报告交付中文、英文两份完整正文。目标用户覆盖中美，并面向更多国家；英文是必要交付，不是可选摘要。两种语言表达同一 Manager、方法、研究版本及信息截止下的判断。

## 1. 一份报告代表什么

报告表达“某位 Manager 在某个信息截止、投资期限和方法下，对某家公司形成的判断”。它是持续案例的发布版本；研究正文可以更新为新版本，旧判断及当时依据保留。

| 必须标识 | 含义 |
| --- | --- |
| 研究对象 | 公司与具体证券身份；涉及每股价值时明确股类、币种及口径，不能只依赖简称 |
| 判断责任 | Manager 身份、方法版本、适用投资期限；不把底层模型名当作投资风格 |
| 时间与范围 | 公开信息截止、所用财报期间、行情时点、报告发布时间；日期精度不足时说明，不能混称“最新” |
| 版本与覆盖 | 报告/案例版本、父版本、公司主报告或限定专题、研究覆盖与实质缺口 |
| 报告语言 | 中文与英文分别标识，关联同一研究版本；报告语言与引用来源的语言、地区及版本身份分开 |

看过一份年报不自动意味着已完成公司投资研究。若只覆盖该材料，内部产物按有限范围留档；首次核心研究未完成时，前台仍显示“研究中”，不能以有限范围专题代替首次正式公司报告。

### 中文与英文的完整交付

- 两份正文均独立回答共同必答问题，不能用一份完整报告加另一语言摘要替代；公司报告、组合报告均遵循这一交付规则。
- 两份报告的公司/证券、Manager、方法、研究版本、信息截止、证据及计算依据一致。数字、单位、币种、期间、情景假设、判断、风险、未知及条件表达须一致；“可能”“尚未证实”等限定不能在转换语言时丢失。
- 保留来源原文和可追溯引用。译文或释义须与原文区分，不改写来源身份，不将不同语言或地区的官方材料静默合并为同一来源。
- 研究质量审阅与语言间一致性核验分别负责内容成立和表达忠实；双语一致不证明研究正确，研究通过也不证明翻译无误。两份正文完成且适用检查通过后才满足本版本的双语交付要求。
- 研究判断更新同步落实到两个语种，保留各自历史产物及共同研究版本关系。单语缺失或转换失败不能标为双语交付完成，也不能让同名当前版本承载不同判断。

语言生成顺序、模型和执行方式属于待验证实现，不指定中文或英文为唯一研究语言，也不因两种语言创建两套独立投资观点。面向更多国家是产品方向，当前确认的报告语种为中文和英文。

## 2. 将共同必答问题组织为八部分的建议

共同必答问题与灵活论证已确认；以下八部分的拆分、顺序及具体要求仍为提案，不是固定模板。报告可以保留充分研究后仍“不足以判断”的内容，但须说明原因及其影响，不能用这个标签掩盖必需研究尚未完成。

| 部分 | 用户应获得的回答 | 深度要求 |
| --- | --- | --- |
| 1. 结论与适用条件 | 当前怎么看、为什么、适用于什么期限和价格、最大疑点是什么？相对上一版有什么实质变化？ | 摘要先给 Manager 的完整主张与限制；结论强度不能超过正文，条件判断不能被压缩成无条件买入 |
| 2. 业务与商业质量 | 谁付钱、买什么、为何选择它；利润和现金从哪里来；竞争、行业位置与资本配置如何影响持续回报？ | 解释收入到现金的经营机制，识别关键业务及共同风险；相关历史数据、竞争与资本投入用于论证，不能只改写业务简介 |
| 3. 核心 thesis | 为什么这项投资可能在本期限内产生回报？哪些关键假设必须成立？ | 把业务变化、经营结果、每股价值或阶段性定价联系起来；说明最重要的因果机制、替代解释与可观察失效条件 |
| 4. 因素、风险与证据 | 目前关注什么、为什么重要、哪些证据支持或削弱判断？ | 每个重要因素连接具体 thesis 和业务传导；区分披露事实、归属明确的说法、假设、推断与未知；呈现最强反证及 Manager 的处理 |
| 5. 估值与价格 | 在明确假设下价值或回报区间如何形成？当前价格要求哪些条件？下行情景是什么？ | 依据、关键假设、计算和敏感性可追溯；股数、净现金/负债和稀释等在所选方法需要时明确。不能用单一目标价或低倍数代替论证 |
| 6. 投资判断与行动条件 | 在该方法、价格和期限下，选择参与、等待、继续持有、减少/退出或放弃的理由是什么？ | 区分公司质量、价格吸引力与行动时机；持有/调整引用真实模拟持仓与决策，没有持仓不能假装持有；资料不足不默认 HOLD |
| 7. 跟踪与更新 | 接下来验证什么、看什么来源、何时应重新判断？ | 跟踪项写明关联假设、可观察条件、复核时点/触发和影响；不写“持续关注”就结束，原期限不能无痕后移 |
| 8. 分歧与研究边界 | 其他 Manager 或已获取机构材料在哪些假设上不同？本报告没解决什么？ | 比较已发布、可定位的观点及其截止/期限；无可得机构材料则说明缺口。保留独立结论，不生成必须服从的共识评级 |

已确认机构研报对照采用“有可用材料就对照”：标明机构、报告时点、适用期限、关键假设及分歧；没有可用研报时说明对照覆盖缺口，自身核心研究、必需资料及审阅完成后仍可发布。机构对照缺口不自动等于核心研究缺失，也不能被用来免除自身研究任务；外部观点不替代独立证据与 Manager 判断。

投资判断表达该 Manager 的方法立场，不预设用户个人资产和适配结论。公司报告负责是否买、适用价格与条件；当前/目标权重、调仓及整体风险取舍由组合报告交付，两份报告互相引用。报告不直接写账户或生成已成交状态。组合报告仅向用户展示比例及归一化表现，隐藏名义资金留在内部。

各 Manager 的模拟账户已选择各自准备好后启动，组合报告明确自身起点和评价区间；SPY 主对照、QQQ 补充对照与该 Manager 使用匹配区间。Manager 间比较另列共同日历区间，不直接以不同起点累计收益判定优劣。尚未取得参考行情、或订单/资金检查未通过的动作保持未成交，不能在报告中写成已买入。

组合报告的主结果统一标识为：单边成交额 0.10% 的模拟交易成本、按 EFFR 参考计息、投资者税前。0%／0.25% 成本情景及零现金利息对照作为辅助结果单列，不与主结果混合或择优替换。引用账户计算版本、利率覆盖及缺口；实验成本不冒充真实券商费用，模拟计息不冒充实际到账收益，税前不表示实际免税。两种报告语言保留同一核算说明。

已确认支持碎股，且卖出款完成结算后才可用于买入。组合报告区分目标比例、实际已成交持仓比例、可用资金及待结算款项；不把包含待结算款项的总权益视为立即可投资资金。若调仓因结算或资金预留尚未完成，明确实际仓位与目标的差异及原因，不写成已买入，也不据此推断 Manager 主动选择等待。名义金额仍只留内部，面向用户用比例和状态说明；ETF 对照使用相同数量与资金政策，双语保持一致。

## 3. 两种 Manager 如何使用同一结构

| 必答问题 | 长期价值型侧重 | 阶段性进攻型侧重 |
| --- | --- | --- |
| 回报从哪里来 | 商业质量、现金创造、再投资及资本配置如何形成多年每股价值 | 经营或事件变化可能令什么预期重新定价；有何证据认为尚未充分反映 |
| 期限如何成立 | 明确采用 1～3 年、3～5 年或其他已配置期限，讨论跨周期承受能力 | 明确采用 1～3 个月、3～6 个月或其他已配置窗口，解释催化与验证时间 |
| 如何估值 | 所选现金流/分部/交叉检查方法的依据、关键假设与价格条件 | 同样需要价格与下行依据，并解释在窗口内可能兑现到何种情景；不能只写趋势上涨 |
| 什么会推翻判断 | 竞争、资本回报、现金质量、治理等关键机制变化 | 催化失效、兑现滞后、预期已被价格反映及基本面恶化；事前写明如何处理 |
| 何时行动或等待 | 价格与可承担的不确定性是否匹配 | 剩余机会、事件时间、价格及退出条件是否匹配 |

期限是方法的一部分；不能仅把同一报告的持有时间改短，就称为另一位 Manager。也不要求两位 Manager 总是意见相反：相同判断需分别有依据，分歧需指出对应假设。

“市场预期”须说明依据。没有可靠共识数据时，可使用明确假设下的价格隐含情景，并标为模型推导；不能将自身判断冒充市场共识。

## 4. 单条重要判断应如何写

正文中的重要主张至少回答下列关系；不要求前台逐项暴露技术字段。

| 要素 | 要表达什么 |
| --- | --- |
| 主张与期间 | Manager 具体认为会发生什么，适用于哪个业务、期间和投资窗口 |
| 依据 | 哪些披露事实、原文或可复算结果支撑；来源中实际发生、管理层计划和一般描述分开 |
| 推断与假设 | 从依据到结论增加了哪些假设，因果路径是否成立，是否存在其他解释 |
| 最强反证 | 什么证据削弱主张；为什么仍接受、降低判断强度或改变结论 |
| 价值与动作含义 | 影响收入、利润、现金、价格或时间中的哪一环；影响是否足以改变原结论 |
| 未知与验证 | 哪些无法观察或尚未获取，如何影响结论，下一步凭什么证据复核 |

证据的支持/反对方向相对于具体主张记录，同一披露可能支持需求增长，也可能暴露现金回收风险。引用合法与引文支持推断分别检查。判断不以模型自报置信度代替这些关系。

## 5. 质量验收：内容齐全之后还要成立

| 检查 | 合格表现 | 不合格例子 |
| --- | --- | --- |
| 独立可读 | 不追问、不打开辅助视图也能理解核心结论、理由和限制；原文与计算可进一步展开 | 摘要只有评级，论据散落在 Agent 对话里 |
| 来源与时间 | 关键事实同公司/期间/来源口径，引用支持实际主张；只使用截止时可得信息 | 引文真实却属于另一期间，或把后续披露写成当时已知 |
| 业务与因果 | 说明为什么会影响经营、现金或定价，识别关键变量和替代解释 | “行业空间大，所以公司一定受益” |
| 反证与风险 | 处理最可能改变结论的反证，说明影响路径和 Manager 的取舍 | 只列通用风险，或把 Reviewer 同意当作反证处理 |
| 估值与行动 | 输入、假设、计算、时间及适用条件匹配，价格依据不足就不下确定结论 | 目标价没有计算依据；缺行情却说当前低估；上涨空间被当作保证收益 |
| 未知与覆盖 | 区分研究尚未完成与研究充分后仍不可知；说明缺口对结论的影响 | 每节都填“未知”却标完整；或为了出结论填造关键数据 |
| 持续研究 | 新版本解释事实、假设和判断分别变了什么，旧版本可还原 | 一句“逻辑不变”，不处理新反证；用新版本覆盖原失误 |
| 双语交付 | 中文与英文均为完整正文，引用可追溯，数字、判断、风险与条件一致 | 英文只有摘要；译文把条件判断写成确定事实；两种语言引用不同研究版本却标为同一版 |

程序检查负责身份、来源、字段、引用、公式与版本；内容审阅负责解释、遗漏、反证和结论强度；独立评测再检验稳定性与泛化。审阅通过不等于投资结果已证明有效。

已确认 Reviewer 的职责是守住研究质量，不要求各方对投资立场达成一致。事实、引用、计算及推理检查通过后，对未来预期或风险取舍的分歧可由 Manager 回应并保留，Manager 对最终判断负责；关键质量问题不能仅以“观点不同”跳过。

完整审阅已确认先取得研究问题、Manager 方法/期限及同范围资料形成独立初判，初判阶段不提供作者报告、摘要或结论；之后再对照报告。首次发布、核心 thesis/关键估值假设改变或重要新证据涉及核心判断时完整审阅；局部修正检查修改及影响，必要时扩审。结论未变不能免除重要反证的审阅。上述为已确认目标流程，当前是否实现须另行验收。

实质错引、跨公司/期间、前视信息、不可复现关键计算等问题，不能靠其他章节得分抵消；须修正或撤回受影响主张。普通经营不确定性允许用情景、限制和观察条件表达，不要求预测必然正确。

## 6. 覆盖、判断与发布分别记录

以下是产品语义，尚不是新增 enum 或已实现 Schema。

| 维度 | 要避免的混淆 |
| --- | --- |
| 研究覆盖 | 公司核心问题已充分研究 / 仅完成限定专题 / 仍有重要研究任务未完成，分别说明 |
| 投资判断 | 支持参与、选择等待、不具吸引力、无法判断等是 Manager 结论；与运行成功失败分开 |
| 发布状态 | 候选、内部采纳、对外发布及当前适用性分开；首次核心研究未完成不对外发布；旧版待复核时保留正文并展示受影响范围 |
| 账户行动 | 报告中的研究判断、正式组合决策、模拟执行结果相互引用，各自有记录 |

例如没有可核验价格，就不能回答“当前是否低估”；已完成的业务研究可作为内部产物保留，不能据此绕过首次公司报告的完整研究要求。反之，未来需求不可确定是投资研究的正常限制，不能只因此把充分论证的情景报告全部判为失败。

基础资料采集与内部研究可并行，首次报告发布前必需资料须就绪。已确认首版准备最近 5 个完整财年与最近 8 个季度，更早资料按需补充；以目标公司财年、信息截止和实际公开情况确定具体范围。实际公开历史不足时允许按实际范围研究并说明限制，已公开却未获取成功不适用该例外。具体准备契约见 [Data Agent 任务卡](UTEKI_AGENT_CONTRACTS_v1.zh-CN.md)。

已确认提前准备覆盖所选研究窗口的历史每日价格、成交量及拆股、分红记录。估值和市场表现计算引用明确证券、价格时点及复权口径；未来数据不能回填历史决策。该准备范围不代表行情已经取得，缺口和影响须按实际披露。

已确认可使用名单外竞争对手、供应商、客户等公司的公开资料，报告须保留其真实主体和来源，并说明对目标公司判断的意义；相关公司证据不冒充目标公司事实，也不使相关公司自动进入持续研究或投资名单。

已确认材料门槛：约定历史窗口及信息截止内，公司实际已公开的年季报、重大公告、官方业绩新闻稿必须达到可研究状态。演示材料、电话会等补充材料获取或解析失败时，须有可核验依据并经研究审阅确认不影响核心判断，才可注明缺口后发布；无法排除核心影响时须补齐。缺口与审阅依据保留，不能把允许发布写成全部材料齐备，也不能仅因未拿到材料就认定其不重要。

## 7. 报告如何持续更新

- **公司主报告：** 当前完整观点；重要更新形成新版本，旧报告保留。默认阅读正式主报告。
- **更新说明：** 附在新版本前部，指出新事实、受影响假设、结论变与不变的理由；只列实质差异，读者无需重读全文寻找变化。
- **专题附件：** 深入资本投入、行业风险或机构观点等限定问题；关键结论进入主报告，不用附件替代主报告的核心解释。

日频检查不要求每天重写报告。确有影响的新信息或复核结果才形成实质更新；检查失败、尚未完成与已检查无变化分别展示。用户不需要审批普通研究迭代或驱动内部取证。

## 8. GOOGL 的一个结构示例

**以下是设计用假设场景，不是已完成的 GOOGL 研究或当前投资建议；不提供虚构金额、价格、证据 ID 或预期回报。**

问题：新增资本投入能否带来足以支持价值判断的现金回报？假设选定材料只披露总额、用途和部分经营结果，无法直接分离新增投入的回报。

| 报告需要说清 | 本例如何交付 |
| --- | --- |
| 已知 | 实际投入、披露用途和管理层计划各自引用选定原文；金额、期间、单位须由真实数据任务取得，此处留空 |
| 待论证 thesis | 明确提出“投入在何种需求、利用率、价格和成本条件下可能转成现金回报”的假设；不将投入增长本身视为 thesis 已证实 |
| 因素与反证 | 围绕可用披露研究需求兑现、利用率/竞争及后续资本需求；缺少可观察指标时说明限制，不自行补出指标值 |
| 估值影响 | 若投入与现金回收时间改变，说明模型哪项假设受影响；未有可核验价格和完整计算前，不给当前高估/低估结论 |
| 两位 Manager | 长期型检验多年回报与买入条件；阶段型检验窗口内何种事件能证实变化。两者都可选择等待，但理由和复核条件可以不同 |
| 对外完整交付 | 报告直接写明能支持什么、尚不能支持什么；无需用户再问“那风险呢”“这是否证明 AI 回报”“现在能不能买”才披露关键限制 |

仅有“资本投入增加、长期利好”及若干链接，不能通过该子问题的内容验收。只有一份年报数据任务完成时，先交付内部限定研究；首次公司报告仍为“研究中”，不能标为完整公司投资报告。

## 9. 从报告反推内部交付

| 内部责任 | 对报告质量直接负责的交付 |
| --- | --- |
| Data | 同范围的披露事实、原文、期间/口径、确定性计算、缺口；允许研究侧继续访问相关上下文 |
| Analysis | 业务机制、thesis 论证、正反证据、情景估值及完整报告候选；不足事实作为明确数据请求 |
| 内容审阅 | 对具体主张的错项、漏项、替代解释和结论强度提出有依据的发现；作者逐项处理 |
| Manager | 方法、期限、关键取舍、最终观点及适用条件；有组合决定时关联正式决策，不凭报告生成虚构持仓 |
| 版本与发布 | 固定正文、结构化字段、证据及时间/版本；读者看到的摘要与正文一致，比较引用明确的正式版本 |
