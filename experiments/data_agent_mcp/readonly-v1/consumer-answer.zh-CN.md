## 数据库缺口与审核状态

- AMD 营收、营业利润来自 `amd-fy2023-formal-batch-00-v1`，现金来自 `amd-fy2023-main-agent-v2`。3 条记录均为 `candidate`，外部审核为 `value_scope_matched`，总体审核 `partial`，采纳仍是 `unchanged_candidate`。数值、所选年度列、单位等有审核支持，不代表完整映射或整个财报已通过。
- 两个 AMD 候选版本均公开报告 `implementation_archive_metadata_mismatch`：冻结文件哈希有效，但声明的部分实现哈希与归档不匹配，历史运行重现性有缺口。营收、营业利润的外部审核还明确没有独立验证目录财年起点；本次补读财年说明不回写原审核。
- AMD 经营现金流与现金资本支出：精确期间查询均返回 `source_present_unprocessed`。本次从完整现金流量表补读，只归为 reading。
- 台积电 `tsmc-annual-v2` 的 `normalized_record_count=0`、`review.status=not_reviewed`。营收、营业利润、经营现金流、资本支出查询均为 `source_present_unprocessed`；现金查询为 `unsupported / unknown_entity_or_metric`。5 项全由本次阅读补充。
- 数值层面没有空格；结构化数据库仍缺 7/10 项，已采纳记录为 0/10。台积电营业利润还有正式主表精度读取缺口；采用已完整读取的 MD&A 整数百万元数值，没有把搜索预览中的更细精度当作完整原文证据。没有将缺行解释成 0、未披露，或换公司、换年度填补。

## 工具可用性障碍与真实调用

实际发出 **43 次 tools/call + 1 次 tools/list = 44 次 MCP 请求**，未超 45 次 tools/call 限额。tools/call 细分：discover_data 2 次，get_data_schema 10 次，query_facts 5 次，read_source 26 次（outline 2、search 12、read 12）。未调用网页、外部数据商、模型提取或写入工具，也未读取仓库代码、配置、数据集、历史答案或记忆。

1. **期间发现不完整。** AMD 两个已有候选事实的版本 `get_data_schema(view=periods)` 都返回空；`period:null` 合法但查询营收/利润/现金均返回 `source_missing`，容易让消费者误判无数据。通过 examples 视图拿到精确 source 期间后重试，3 项成功命中。这些初次 source_missing 不作为最后的财务缺口。
2. **搜索的条件必填字段未在工具 schema 表达。** 两次省略 node_id 的搜索失败，原错误为 `Value error, search requires: node_id, phrase`。先 outline 获取 node_id 后恢复。2 次计入调用数。
3. **大表响应上限缺少恢复指引。** 台积电利润表以 count=5 和 count=3 读取均失败；现金流跨页 count=12 失败。3 次均返回 `context_too_large`、`blocks=[]`、`next_cursor=null`，详情为 `Full atomic context exceeds the response limit; no blocks read or continuation advanced.`。现金流分为单页 count=3 后恢复；营业利润改读同年报 MD&A；营收从 Note 22 完整表恢复。
4. **章节索引有限。** 台积电 outline 报 `item_unresolved: No visible legal Item body headings were found.`，只有文档/Part 层；AMD outline 也有 TOC anchor 冲突等诊断。仍可在文档节点检索。未把索引“available”理解为所有章节解析无误。
5. **输出重复与诊断区分。** 各次 schema/查询反复附带较长 data_state；source-stage numeric=0 与注册候选版本的 normalized_record_count=9/3 需要消费者自行区分。search 的 limited 是导航分页，不代表未披露；本次只完整读取目标块，没有声称全报告审阅或穷尽检索。

未来期间验证：对 AMD 和台积电使用同一截止日 2026-10-04，明确请求报告期末 2030-01-01 至 2030-12-31。discover_data 返回 `status=unavailable`、空 items、两家各一条 `no_registered_source_matches_scope`，没有回退到 2023 或其他公司。它证明的是该冻结目录没有符合所选范围的来源，不能据此宣称公司未来不披露、未来数值为零，或提前存在 FY2030 年报。
