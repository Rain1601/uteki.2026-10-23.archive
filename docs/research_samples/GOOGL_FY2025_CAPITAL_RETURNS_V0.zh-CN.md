## 2. 按能力分工的研究任务

SOTA 是执行配置中的能力档位，具体模型由后续版本化配置绑定。以下是可交接的任务设计，尚未接入自动分派。

| 任务 | 执行安排 | 明确交付与验收 |
| --- | --- | --- |
| P：定义问题与研究计划 | SOTA | 解释为何研究投入与现金回报，拆分事实、会计、需求及价值问题；给出子任务、依赖、完成条件和已知材料限制 |
| W1：定位现金流和资本支出 | 合适的性价比模型＋原文读取工具 | 返回原表、年列、单位、币种、现金／非现金范围及来源位置；无法定位单位则返回缺口，不自行假定 |
| W2：整理资产与成本确认 | 合适的性价比模型 | 提取投入用途、投用时点、折旧政策和管理层未来预期；不能把计划写成已经发生，不能把折旧当作维护资本支出 |
| W3：寻找相反证据和遗漏 | 合适的性价比模型处理限定范围检索 | 返回闲置、合同义务、回款、利用率和现金流口径的相关原文；发现不到不等于不存在，说明实际检查范围 |
| C：复算指定指标 | 确定性程序 | 检查所选原件／表格身份与单位，输出输入值、公式、计算结果及单元格位置；模型不自行决定未声明的口径 |
| R：关键推理与反证 | SOTA，审阅职责独立 | 检查现金流变化能否归因于新增投资、会计时间差及替代解释；必要时重读原文、退回或新增任务，不凭子任务摘要认定事实 |
| S：形成案例及后续计划 | SOTA | 记录目前能判断什么、不能判断什么、何种新证据改变判断；选定案例版本，并将观察需求交给持续追踪能力 |

子任务统一交接：任务身份与版本、公司／材料／截止、具体问题、允许的来源和动作、交付要求、资源边界。返回证据引用、事实或管理层主张、计算输入、缺口及执行状态。关键输入缺失、口径冲突、复杂推断或重复失败返回规划角色处理；模型升级不能把缺失数据变成已知事实。

## 4. 一项实际完成的计算

公式为：**合并经营现金流 − 现金购置 property and equipment**。这是明确口径的历史现金流差额，没有对维护投入、股权激励、非现金购置或其它项目作所有者收益调整。

单位：百万美元。原表 row 2 给出年列，row 19 为经营现金流，row 21 为购置 PP&E；现金支出取正数后相减。

| 年度 | 经营现金流 | 现金购置 PP&E | 两者差额 |
| --- | ---: | ---: | ---: |
| 2023 | 101,746 | 32,251 | 69,495 |
| 2024 | 125,299 | 52,535 | 72,764 |
| 2025 | 164,713 | 91,447 | 73,266 |

按上述公式计算，2025 相对 2024：经营现金流增加约 31.46%，现金购置 PP&E 增加约 74.07%，差额增加约 0.69%。[完整输入、单元格位置、哈希与计算结果](../../experiments/architecture_baseline/2026-09-29-capital-returns-v0/calculations.json)已保存。

**一个实际发现的索引缺口：**v0.1 的表格块没有保存相邻的单位说明。本次从相同哈希的原件 `/html/body/div[837]/span` 核对到 `(in millions)`，紧随表格为 `/html/body/div[837]/table`。补充定位单独记录，没有修改旧索引，也没有声称单位已被原索引完整保留。币种与表内美元符号及同份文件资本支出文字交叉核对。

这项计算支持“现金流增长需要结合资本投入一起分析”的研究问题。它不能证明投入损害了长期价值，也不能证明新增投入已经取得回报；未来收益、投入用途、成本确认和税收时点影响仍需分别解释。

## 5. 初步研究解释与下一步

可以形成的初步问题是：**经营现金创造扩大时，新增投入如何转换成未来可分配现金？** 当年现金流差额变化很小，是继续调查的起点；判断投资好坏还需要投入归属、兑现时间和价值假设。

长期 manager 需要进一步识别投入中维持业务与扩张业务的部分、未来增量收入和成本、资产利用及经济寿命。阶段性进攻 manager 还需要具体事件窗口、当时市场预期及行情；本份年报本身不足以确认数月内可执行的机会。

当前需要追踪但尚未解决的内容包括：新增资产分别服务哪些业务及需求、投用与利用率、单位服务成本、增量收入或利润与投入的对应、税收影响的具体金额和持续性。这里的“尚未解决”指本次已核对证据的边界，不代表已证明公司从未披露。

下一步优先顺序：

1. 在同一份年报内定向核对资本资产构成、已投用／未投用资产和业务投入归属，逐项记录能回答及无法回答的问题。
2. 用一个 SOTA 规划／综合角色和一个明确范围的子任务角色接通来源读取、结果回传、升级及独立反证；具体型号与接入配置仍待绑定。
3. 扩充行业、事件及行情材料时建立新版本，形成完整案例；研究流程和账户核算分别验收。

本轮验证完成的是原文定位、声明口径的计算及任务样例；尚未验证自动规划、多模型成本节省、完整研究质量或投资收益。
