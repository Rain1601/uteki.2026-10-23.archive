# Claude 单次请求的有界重试

2026-10-09。适用于 `SdkAutonomousPlanner`（包括 Worker）与
`SdkRecordReviewer` 的原生 AIHubMix Claude 请求。只改变瞬时故障处理，
不改变任务、提示词、模型返回契约或业务规则。

## 配置与边界

模型配置使用现有 `max_retries`，默认 `0`，只接受整数 `0..3`。
`1` 表示初次请求失败后最多补发一次；推荐真实任务先使用 `1`。
每次补发继续使用相同输入和请求配置，建立独立 call ID、费用预留和尝试记录。
HTTP 传输与 SDK 内部重试仍为 `0`；配置切面中的传输层 `max_retries: 0`
与外层模型配置的 `max_retries: 1` 分别描述这两个边界。

重试适用：连接/读取/写入失败、瞬时 SSL 故障（不含证书校验失败）、
远端协议中断、超时、HTTP 408/429/500/502/503/504/529。
流式调用的断流、截断事件和明确的临时服务错误也归类为瞬时故障；
不会拼接两次请求的部分输出。
HTTP 400/401 等永久错误、证书校验失败、完整响应的 JSON/Schema 错误、
输出额度不足和取消不走网络重试。延迟依次为 0.25、0.5、1 秒。

`request_timeout` 约束每次尝试，Agent 的 `limits.turn_timeout` 约束完整决策，
包含重试与日志处理。例：每次请求 120 秒、最多一次重试时，应给完整决策
留出超过 240.25 秒的时间；现有完整决策上限为 300 秒。外层取消会立即停止，
不会强行重试。不会因为允许重试而重放已完成的读材料或执行动作。

## 费用与失败记录

发送后断流、读取超时或裸 SSL 异常保留未知费用的全额预留。
只有传输能够证明未发送的连接建立失败可按原有规则结算为未发送。
在限额模式下，调用者若希望未知预留存在时继续，应显式设置
`allow_unknown_reservations: true`；未知预留仍占用同一预算。
`record_only` 继续记录每次真实/未知费用。`max_requests_total` 继续约束所有尝试。
重试不重建账本、不核销未知费用，不隐藏费用不足导致的停止。

`decision-XXXX-attempt-YY.json` 或 `review-XXXX-attempt-YY.json` 记录每次尝试、
关联 calls、固定错误类别、已保留的可见输出和下一次重试延迟。
失败耗尽时抛出明确错误；不会把失败视为通过或运行宿主工具。
敏感传输异常原文不写入错误提示。

本次验证仅使用本地模拟 HTTP/SSL。覆盖同一请求重试、未知费用、预算阻断、
重试耗尽、永久错误、取消、审阅请求，以及完成一次读取后第三个决策重试，
确认读取动作只执行一次。真实网络稳定性仍由后续任务运行检验。
